# Icons & Image

## Purpose

Three icon+text rows beside a large image column (left or right). Component name: **Icons & Image** (`partials/sections/content/icons-and-image/`). `enableConfig: true`, priority 25.

## When to use

- Feature list with a supporting product or lifestyle image
- “How it works” sections with visual anchor
- Alternating layout pages (toggle `imagePosition` per instance)
- Richer than **Text & Image** when multiple bullet features are needed

## When not to use

- Centred three icons without image — use **Icon Banner**
- Four equal columns — use **Showcase**
- Photo tiles with per-tile CTAs — use **Info Tiles**
- Hero placement — use **Two Column Hero**

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `icon{N}Title`, `icon{N}Description` | string (HTML) | Optional | N = 1, 2, 3 |
| `icon{N}Svg` | string (HTML) | Optional | Custom SVG inner HTML |
| `item{N}ViewBox`, `item{N}Width`, `item{N}Height` | — | Optional | SVG dimensions (note: item prefix for viewBox) |
| `imageSrc` | URL | Recommended | ~768px wide |
| `imageAlt` | string | Recommended | |
| `imageId` | string | Optional | DOM id |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `imagePosition` | string | `right` | `left` or `right` |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Missing `imageSrc` — shows empty placeholder
- Only filling one of three icon rows
- Duplicate content as **Text & Image** on the same page without variation
- Huge image with minimal icon copy

## Examples

```json
{
  "icon1Title": "Connect",
  "icon1Description": "Integrate with your existing tools.",
  "icon2Title": "Automate",
  "icon2Description": "Reduce manual work.",
  "icon3Title": "Analyse",
  "icon3Description": "Clear reporting dashboards.",
  "imageSrc": "/assets/img/dashboard.jpg",
  "imageAlt": "Product dashboard",
  "config": {
    "imagePosition": "right"
  }
}
```
