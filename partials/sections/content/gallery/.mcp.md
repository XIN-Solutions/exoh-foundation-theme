# Image Gallery

**Type:** `content/gallery`

## Purpose

Single image or carousel of images in a configurable content width.

## When to use

- Product or portfolio image sets
- Before/after or process photo sequences
- Autoplaying image slideshows
- Single hero-style image within content width

## When not to use

- Side-by-side text and one image — use **Text & Image** (`content/text-and-image`)
- Icon feature grid — use **Showcase** (`content/column-showcase`)
- Photo tiles with titles and CTAs — use **Info Tiles** (`content/info-tiles`)
- Full-bleed background images — use a hero section (`hero/*`)

## Key fields and constraints

Set images and layout via **`config`** on **`append_section`** / **`update_section`**. No **`model`** fields.

Single image: static display. Two or more: carousel.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `images` | string[] | — | **Required** — array of image URLs; warning if empty |
| `columnSize` | string | `12` | Content width (`1`–`12`) |
| `autoplay` | boolean | false | Autoplay (only when 2+ images) |
| `switchAfterSeconds` | number | `5` | Autoplay delay in seconds |
| `showSlideDots` | boolean | false | Pagination dots |
| `showNavigationArrows` | boolean | false | Prev/next arrows |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Empty `images` array — warning alert
- Mixing vastly different aspect ratios in one carousel
- Autoplay with very fast `switchAfterSeconds` (< 3)
- Using for video — use **Embedded Video** (`content/embedded-video`)

## Examples

Pass as `config` argument to **`append_section`** or **`update_section`**.

```json
{
  "images": [
    "/assets/img/gallery-1.jpg",
    "/assets/img/gallery-2.jpg",
    "/assets/img/gallery-3.jpg"
  ],
  "autoplay": true,
  "switchAfterSeconds": 6,
  "showNavigationArrows": true
}
```

Single image:

```json
{
  "images": ["/assets/img/showcase.jpg"],
  "columnSize": "8"
}
```
