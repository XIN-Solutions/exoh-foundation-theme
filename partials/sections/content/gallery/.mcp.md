# Image Gallery

## Purpose

Single image or Swiper carousel of images in a configurable content width. Component name: **Image Gallery** (`partials/sections/content/gallery/`). `enableConfig: true`, priority 25.

## When to use

- Product or portfolio image sets
- Before/after or process photo sequences
- Autoplaying image slideshows
- Single hero-style image within content width

## When not to use

- Side-by-side text and one image — use **Text & Image**
- Icon feature grid — use **Showcase**
- Photo tiles with titles and CTAs — use **Info Tiles**
- Full-bleed background images — use a hero component

## Key fields and constraints

### Model fields

None — images live in `config.images`.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `images` | string[] | — | **Required** — array of image URLs; warning if empty |
| `columnSize` | string | `12` | Bootstrap width (`1`–`12`) |
| `autoplay` | boolean | false | Swiper autoplay (only when 2+ images) |
| `switchAfterSeconds` | number | `5` | Autoplay delay in seconds |
| `showSlideDots` | boolean | false | Pagination dots |
| `showNavigationArrows` | boolean | false | Prev/next arrows |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

Single image: static `<img>`. Two or more: Swiper carousel.

## Anti-patterns

- Empty `images` array — warning alert
- Mixing vastly different aspect ratios in one carousel
- Autoplay with very fast `switchAfterSeconds` (< 3)
- Using for video — use **Embedded Video**

## Examples

```json
{
  "config": {
    "images": [
      "/assets/img/gallery-1.jpg",
      "/assets/img/gallery-2.jpg",
      "/assets/img/gallery-3.jpg"
    ],
    "autoplay": true,
    "switchAfterSeconds": 6,
    "showNavigationArrows": true
  }
}
```

Single image:

```json
{
  "config": {
    "images": ["/assets/img/showcase.jpg"],
    "columnSize": "8"
  }
}
```
