# Freeform Columns

**Type:** `content/freeform-columns`

## Purpose

Flexible multi-column layout (1–6 columns) with per-column HTML content and optional custom column classes.

## When to use

- Custom column layouts not covered by other sections
- Mixed HTML blocks side by side (e.g. pricing tables, comparison grids)
- Experiments requiring per-column class overrides

## When not to use

- Standard icon features — use **Showcase** (`content/column-showcase`) or **Info Tiles** (`content/info-tiles`)
- Text + single image — use **Text & Image** (`content/text-and-image`)
- Markdown article body — use **Markdown Text** (`content/markdown-text`)
- When a purpose-built section fits — prefer structured sections over freeform HTML

May not appear in **`list_section_types`** when disabled in the theme.

## Key fields and constraints

Set column content via **`model`** and layout via **`config`** on **`append_section`** / **`update_section`**.

Columns 2–6 only render when `config.columns` requires them.

### Model fields (per column, N = 1..6)

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `col{N}Content` | string (HTML) | Optional | Column body; placeholder "Column" if empty |
| `col{N}Classes` | string | Optional | Grid classes; defaults from `config.columns` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `columns` | string | `four` | `one`, `two`, `three`, `four`, `five`, `six` |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Large unstructured HTML blobs without semantic markup
- Nested section-like layouts inside columns
- Using when **Text & Image** or **Info Tiles** would give better structure
- Setting `columns: six` with content in only one column

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "col1Content": "<h3>Plan A</h3><p>For individuals.</p>",
  "col2Content": "<h3>Plan B</h3><p>For teams.</p>"
}
```

**Config:**

```json
{
  "columns": "two"
}
```
