# Bento

**Type:** `content/bento`

## Purpose

Asymmetric four-tile bento grid with a large primary panel (icon, copy, image) and three smaller accent tiles.

## When to use

- Homepage or landing-page feature overview with visual hierarchy
- Product capability summaries where one pillar deserves more space
- Mid-page platform highlights with icon-led tiles
- Marketing sections needing a modern asymmetric grid layout

## When not to use

- Dynamic page listings — use **Belt** (`misc/belt`)
- Side-by-side text and single image — use **Text & Image** (`content/text-and-image`) or **Showcase** (`content/column-showcase`)
- Uniform icon grids without size hierarchy — use **Icon Banner** (`content/icon-banner`) or **Info Tiles** (`content/info-tiles`)
- Photo carousels — use **Image Gallery** (`content/gallery`)

## Key fields and constraints

Set tile content via **`model`** and layout settings via **`config`** on **`append_section`** / **`update_section`**.

Layout is fixed at four tiles: one large primary panel (2×2 grid span) and three smaller accent tiles. Optional links per tile are hidden by default (`config.hide*Link`).

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `sectionTitle` | string (HTML) | Recommended | Centred section heading |
| `sectionDescription` | string (HTML) | Optional | Centred intro copy; hidden when `config.hideSectionDescription` |
| `primaryTitle` | string (HTML) | Recommended | Large tile heading |
| `primaryDescription` | string (HTML) | Optional | Large tile body copy |
| `primaryImageSrc` | URL | Optional | Image at bottom of large tile; defaults to placeholder |
| `primaryImageAlt` | string | Optional | Alt text for primary tile image |
| `primaryIconClass` | string | Optional | Line Awesome classes on primary icon; default `la la-layer-group text-primary` |
| `primaryLinkLabel` | string (HTML) | Optional | Primary tile link label |
| `primaryLinkUrl` | URL | Optional | Primary tile link destination |
| `secondaryTitle` | string (HTML) | Recommended | Top-right tile heading |
| `secondaryDescription` | string (HTML) | Optional | Top-right tile body |
| `secondaryIconClass` | string | Optional | Line Awesome classes; default `la la-globe text-primary` |
| `secondaryLinkLabel` | string (HTML) | Optional | Top-right tile link label |
| `secondaryLinkUrl` | URL | Optional | Top-right tile link destination |
| `tertiaryTitle` | string (HTML) | Recommended | Bottom-left tile heading |
| `tertiaryDescription` | string (HTML) | Optional | Bottom-left tile caption |
| `tertiaryIconClass` | string | Optional | Line Awesome classes; default `la la-shield-alt text-primary` |
| `tertiaryLinkLabel` | string (HTML) | Optional | Bottom-left tile link label |
| `tertiaryLinkUrl` | URL | Optional | Bottom-left tile link destination |
| `quaternaryTitle` | string (HTML) | Recommended | Bottom-right tile heading |
| `quaternaryDescription` | string (HTML) | Optional | Bottom-right tile caption |
| `quaternaryIconClass` | string | Optional | Line Awesome classes; default `la la-magic text-primary` |
| `quaternaryLinkLabel` | string (HTML) | Optional | Bottom-right tile link label |
| `quaternaryLinkUrl` | URL | Optional | Bottom-right tile link destination |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `layoutPreset` | string | `default` | `default` (tall mosaic) or `compact` (shorter grid height) |
| `cells` | array | 4 fixed entries | Read-only span metadata for dialog; `{ id, label, colSpan, rowSpan }` |
| `hideSectionDescription` | boolean | false | Hides centred description below title |
| `hidePrimaryImage` | boolean | false | Hides image in primary panel |
| `hidePrimaryLink` | boolean | true | Hides primary panel link |
| `hideSecondaryLink` | boolean | true | Hides top-right panel link |
| `hideTertiaryLink` | boolean | true | Hides bottom-left panel link |
| `hideQuaternaryLink` | boolean | true | Hides bottom-right panel link |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

## Anti-patterns

- Overly long copy in tertiary/quaternary tiles — those panels use small captions
- Expecting variable tile count — layout is fixed at four tiles with preset spans
- Portrait `primaryImageSrc` in the wide bottom image slot — use landscape imagery
- Using for sequential step-by-step content — use **Process Steps** (`content/process-steps`) when available
- Enabling all four tile links without distinct destinations — duplicates navigation noise

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "sectionTitle": "Platform capabilities",
  "sectionDescription": "Everything you need to build and scale.",
  "primaryTitle": "Unified control plane",
  "primaryDescription": "Manage infrastructure from a single dashboard.",
  "primaryImageSrc": "/assets/img/empty.png",
  "primaryImageAlt": "Dashboard overview",
  "secondaryTitle": "Global edge network",
  "secondaryDescription": "Low-latency delivery worldwide.",
  "tertiaryTitle": "Enterprise security",
  "tertiaryDescription": "SOC 2 compliant",
  "quaternaryTitle": "Smart automation",
  "quaternaryDescription": "AI-assisted workflows"
}
```

**Config:**

```json
{
  "layoutPreset": "default",
  "useAltBackground": false,
  "hideSectionDescription": false,
  "hidePrimaryLink": true
}
```
