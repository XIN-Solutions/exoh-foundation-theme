# Two Column Markdown

**Type:** `content/two-column-markdown`

## Purpose

Renders two independent markdown bodies side by side from the medium breakpoint up, with a configurable width split. Content is stored in **`config`** only; there is no **`model`**.

## When to use

- Comparison or contrast copy where each column has its own markdown source
- FAQ or policy blocks with parallel left and right narratives
- Layouts that need separate editable columns rather than one flowing body

## When not to use

- Single markdown body with CSS multi-column flow — use **Markdown Text** (`content/markdown-text`)
- Image beside structured title and description — use **Text & Image** (`content/text-and-image`)
- Hero headlines — use a hero section (`hero/*`)

## Key fields and constraints

Set all content and layout via **`config`** on **`append_section`** / **`update_section`**. No **`model`** fields.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `markdownLeft` | string | — | Left column markdown |
| `markdownRight` | string | — | Right column markdown |
| `textAlignment` | string | `left` | `left`, `center`, `right`, `justified`; applies to both columns |
| `split` | string | `6-6` | `4-8`, `5-7`, `6-6`, `7-5`, `8-4` — grid share from medium breakpoint up; stacks below |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

Warning appears only when both markdown fields are empty. One empty side renders an empty column.

## Anti-patterns

- Both columns empty — shows a warning instead of content
- Using for one long article that should flow across columns — use **Markdown Text** (`content/markdown-text`) with `textColumns`
- Expecting per-column alignment — one shared `textAlignment` applies to both sides

## Examples

Pass as `config` argument to **`append_section`** or **`update_section`**.

```json
{
  "markdownLeft": "## Left\n\n- Point one\n- Point two",
  "markdownRight": "## Right\n\nSupporting detail.",
  "textAlignment": "left",
  "split": "5-7"
}
```
