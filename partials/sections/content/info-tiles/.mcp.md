# Info Tiles

## Purpose

Grid of image tiles (3 or 4) with title, description, and optional per-tile CTA. Component name: **Info Tiles** (`partials/sections/content/info-tiles/`). `enableConfig: true`, priority 15.

## When to use

- Service or product cards with photos
- “What we offer” grids with learn-more links
- Image-above or image-below tile layouts
- Sections needing 3- or 4-column responsive grids

## When not to use

- SVG icon features without photos — use **Showcase** or **Icon Banner**
- Single text + image — use **Text & Image**
- Dynamic child-page listings — use **Belt**
- Quote cards with author photos — use **Testimonials**

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading; hidden when `config.hideTitle` |
| `tile{N}Title`, `tile{N}Description` | string (HTML) | Optional | N = 1..4 (tile 4 only when `columns: four`) |
| `tile{N}ImageSrc`, `tile{N}ImageAlt` | URL / string | Optional | ~512px images |
| `tile{N}ImageId` | string | Optional | |
| `tile{N}LinkText`, `tile{N}LinkUrl` | string / URL | Optional | CTA; hidden when `config.hideCta` |
| `tile{N}LinkTarget`, `tile{N}LinkRel` | string | Optional | |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `columns` | string | `three` | `three` or `four` |
| `imagePosition` | string | `top` | `top` (image above text) or `below` |
| `hideTitle`, `hideCta` | boolean | false | |
| `centerTileText` | boolean | false | Centre-align tile text |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- `columns: four` with only two tiles populated
- CTA with `tile{N}LinkText` but `tile{N}LinkUrl: "#"`
- Mismatched image aspect ratios across tiles
- Using for team headshots — use **Team**

## Examples

```json
{
  "title": "Our services",
  "tile1Title": "Consulting",
  "tile1Description": "Expert guidance for your project.",
  "tile1ImageSrc": "/assets/img/consulting.jpg",
  "tile1ImageAlt": "Consulting",
  "tile1LinkUrl": "/services/consulting",
  "tile1LinkText": "Learn more",
  "tile2Title": "Implementation",
  "tile2Description": "End-to-end delivery.",
  "tile2ImageSrc": "/assets/img/implementation.jpg",
  "tile2LinkUrl": "/services/implementation",
  "tile2LinkText": "Learn more",
  "config": {
    "columns": "three",
    "imagePosition": "top"
  }
}
```
