# Showcase

**Type:** `content/column-showcase`

## Purpose

Four-column grid of icon features, each with linked title and description.

## When to use

- Product or service feature grids (3–4 items)
- Icon-led value propositions with short copy
- Mid-page "why choose us" sections
- Linked feature titles pointing to detail pages

## When not to use

- Single text + image block — use **Text & Image** (`content/text-and-image`)
- Large side image with icon list — use **Icons & Image** (`content/icons-and-image`)
- Photo tiles with CTAs — use **Info Tiles** (`content/info-tiles`)
- Full-width icon banner on coloured background — use **Icon Banner** (`content/icon-banner`)

## Key fields and constraints

Set inline content via **`model`** and layout settings via **`config`** on **`append_section`** / **`update_section`**.

All four columns always render; unused items show placeholder copy. Layout is fixed at four columns.

### Model fields (per item 1–4)

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `item{N}Title` | string (HTML) | Recommended | Linked heading |
| `item{N}Url` | URL | Optional | Link target for title; default `#` |
| `item{N}Description` | string (HTML) | Optional | |
| `item{N}IconHtml` | string (HTML) | Optional | Custom SVG inner HTML |
| `item{N}ViewBox`, `item{N}Width`, `item{N}Height` | string / number | Optional | SVG dimensions |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- `item{N}Url: "#"` on all items — use real paths or remove links
- Overly complex custom SVG in `item{N}IconHtml`
- Using for testimonials or team members — use **Testimonials** (`misc/testimonials`) or **Team** (`misc/team`)
- Expecting variable column count — layout is fixed at four

## Examples

Pass as `model` argument to **`append_section`** or **`update_section`**.

```json
{
  "item1Title": "Fast setup",
  "item1Url": "/features/setup",
  "item1Description": "Launch in minutes, not weeks.",
  "item2Title": "Secure",
  "item2Url": "/security",
  "item2Description": "Enterprise-grade protection.",
  "item3Title": "Scalable",
  "item3Description": "Grows with your business.",
  "item4Title": "Supported",
  "item4Description": "Expert help when you need it."
}
```
