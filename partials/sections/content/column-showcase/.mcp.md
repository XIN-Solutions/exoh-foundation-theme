# Showcase

## Purpose

Four-column grid of icon features, each with linked title and description. Component name: **Showcase** (`partials/sections/content/column-showcase/`). Priority 20. Template: `standard.hbs` (four fixed columns).

## When to use

- Product or service feature grids (3–4 items)
- Icon-led value propositions with short copy
- Mid-page “why choose us” sections
- Linked feature titles pointing to detail pages

## When not to use

- Single text + image block — use **Text & Image**
- Large side image with icon list — use **Icons & Image**
- Photo tiles with CTAs — use **Info Tiles**
- Full-width icon banner on coloured background — use **Icon Banner**

## Key fields and constraints

### Model fields (per item 1–4)

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `item{N}Title` | string (HTML) | Recommended | Linked heading |
| `item{N}Url` | URL | Optional | Link target for title; default `#` |
| `item{N}Description` | string (HTML) | Optional | |
| `item{N}IconHtml` | string (HTML) | Optional | Custom SVG inner HTML |
| `item{N}ViewBox`, `item{N}Width`, `item{N}Height` | string / number | Optional | SVG dimensions |

All four columns always render; unused items show placeholder copy.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- `item{N}Url: "#"` on all items — use real paths or remove links
- Overly complex custom SVG in `item{N}IconHtml`
- Using for testimonials or team members — use **Testimonials** or **Team**
- Expecting variable column count — layout is fixed at four
