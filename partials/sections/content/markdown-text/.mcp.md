# Markdown Text

**Type:** `content/markdown-text`

## Purpose

Renders author markdown as HTML in a configurable column width, with optional multi-column text flow. Body content is stored in **`config`**, not **`model`**.

## When to use

- Long-form prose, policies, or documentation sections
- Content authored in markdown rather than raw HTML fields
- Multi-column article layout (`textColumns` > 1)
- Pages needing flexible width (`columnSize`) and text alignment

## When not to use

- Hero headlines — use a hero section (`hero/*`)
- Side-by-side image and text — use **Text & Image** (`content/text-and-image`)
- Short feature blurbs with icons — use **Showcase** (`content/column-showcase`)
- Embedded video — use **Embedded Video** (`content/embedded-video`)

## Key fields and constraints

Set all content and layout via **`config`** on **`append_section`** / **`update_section`**. No **`model`** fields.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `markdown` | string | — | **Required** — source markdown; shows warning if empty |
| `columnSize` | string | `12` | Content width (`1`–`12`) |
| `textColumns` | string | `1` | Column count for flowing text |
| `textAlignment` | string | `left` | `left`, `center`, `right`, `justified` |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Empty `config.markdown` — renders a warning alert
- Pasting full page layouts with complex HTML in markdown
- Using for a single headline — overkill; use **Text & Image** (`content/text-and-image`)
- Extremely wide content in narrow `columnSize`

## Examples

Pass as `config` argument to **`append_section`** or **`update_section`**.

```json
{
  "markdown": "## Our approach\n\nWe focus on clarity and speed.\n\n- Simple tools\n- Fast delivery",
  "columnSize": "8",
  "textAlignment": "left"
}
```

Two-column text flow:

```json
{
  "markdown": "Long article body…",
  "textColumns": "2",
  "columnSize": "10"
}
```
