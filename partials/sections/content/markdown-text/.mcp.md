# Markdown Text

## Purpose

Renders author markdown as HTML in a configurable column width, with optional multi-column text flow. Component name: **Markdown Text** (`partials/sections/content/markdown-text/`). `enableConfig: true`, priority 10.

## When to use

- Long-form prose, policies, or documentation sections
- Content authored in markdown rather than raw HTML fields
- Multi-column article layout (`textColumns` > 1)
- Pages needing flexible width (`columnSize`) and text alignment

## When not to use

- Hero headlines — use a hero component
- Side-by-side image and text — use **Text & Image**
- Short feature blurbs with icons — use **Showcase**
- Embedded video — use **Embedded Video**

## Key fields and constraints

### Model fields

No direct model text fields — body content lives in config.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `markdown` | string | — | **Required** — source markdown; shows warning if empty |
| `columnSize` | string | `12` | Bootstrap grid width (`1`–`12`) |
| `textColumns` | string | `1` | CSS `column-count` for flowing text |
| `textAlignment` | string | `left` | `left`, `center`, `right`, `justified` |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Empty `config.markdown` — renders a warning alert
- Pasting full page layouts with complex HTML in markdown
- Using for a single headline — overkill; use **Text & Image**
- Extremely wide content in narrow `columnSize`

## Examples

```json
{
  "config": {
    "markdown": "## Our approach\n\nWe focus on clarity and speed.\n\n- Simple tools\n- Fast delivery",
    "columnSize": "8",
    "textAlignment": "left"
  }
}
```

Two-column text flow:

```json
{
  "config": {
    "markdown": "Long article body…",
    "textColumns": "2",
    "columnSize": "10"
  }
}
```
