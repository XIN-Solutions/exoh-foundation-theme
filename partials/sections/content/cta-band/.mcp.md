# CTA Band

**Type:** `content/cta-band`

## Purpose

Full-width mid-page conversion strip with centred headline, optional description, primary button, and optional secondary text link.

## When to use

- Mid-page conversion breaks between feature sections and pricing or contact
- Closing call to action after social proof (stats, testimonials)
- Simple signup or demo prompts without a full hero or form block
- Campaign landing pages needing a repeated conversion touchpoint

## When not to use

- Above-the-fold hero messaging — use **Hero Image** (`hero/hero`) or **Image Banner** (`hero/image-banner`)
- Email capture with form fields — use **Subscribe** (`misc/subscribe`) or **Split CTA with Form** (`content/split-cta-form`)
- Two-column copy beside an image — use **Text & Image** (`content/text-and-image`)
- Persistent promo copy that should stay visible — keep this section; do not use a dismissible overlay for core CTAs

## Key fields and constraints

Set headline, description, and CTA copy via **`model`**. Set visibility and background via **`config`** on **`append_section`** / **`update_section`**.

Primary CTA requires both **`primaryCtaLabel`** and **`primaryCtaUrl`** for a meaningful published link. Secondary link is optional; hide it with `config.hideSecondaryLink` when not needed.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Section headline; hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Supporting copy below headline; hidden when `config.hideDescription` |
| `primaryCtaLabel` | string (HTML) | Recommended | Primary button label |
| `primaryCtaUrl` | URL | Recommended | Primary button destination; defaults to `#` |
| `primaryCtaClasses` | string | Optional | Button CSS classes; defaults to theme button colour |
| `secondaryLinkLabel` | string (HTML) | Optional | Secondary text link label |
| `secondaryLinkUrl` | URL | Optional | Secondary link destination; defaults to `#` |
| `secondaryLinkClasses` | string | Optional | Secondary link CSS classes |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `hideTitle` | boolean | false | Hides section headline |
| `hideDescription` | boolean | false | Hides description paragraph |
| `hidePrimaryCta` | boolean | false | Hides primary button |
| `hideSecondaryLink` | boolean | false | Hides secondary text link |
| `useAltBackground` | boolean | false | Light alternate background instead of primary colour band |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

## Anti-patterns

- Primary CTA label set without a real `primaryCtaUrl` on published pages
- Hiding both primary button and secondary link — leaves a non-actionable strip
- Long description paragraphs — keep to one or two sentences for scanability
- Duplicating the same CTA copy already in the page hero on the same page
- Using for pricing tier selection — use **Pricing** (`misc/pricing`) instead

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Ready to grow your business?",
  "description": "Start your 14-day free trial today. No credit card required.",
  "primaryCtaLabel": "Start free trial",
  "primaryCtaUrl": "/signup",
  "secondaryLinkLabel": "Talk to sales",
  "secondaryLinkUrl": "/contact"
}
```

**Config:**

```json
{
  "useAltBackground": false,
  "hideSecondaryLink": false
}
```
