# FAQ Accordion

**Type:** `content/faq-accordion`

## Purpose

Expandable question-and-answer accordion for support, pre-sales, and product FAQ blocks. Published markup emits Schema.org `FAQPage` JSON-LD from the configured items.

## When to use

- Pricing or product pages with common buyer questions
- Support and help centre landing sections
- Onboarding pages explaining how the product works
- Any page needing structured Q&A without long static copy

## When not to use

- Long-form prose or policy documents — use **Markdown Text** (`content/markdown-text`)
- Single question with a short answer beside an image — use **Text & Image** (`content/text-and-image`)
- Step-by-step processes — use **Process steps** (`content/process-steps`)
- Comparison matrices — use **Comparison table** (`content/comparison-table`)

## Key fields and constraints

Set section heading via **`model`**. Set FAQ items and layout via **`config`** on **`append_section`** / **`update_section`**.

Works best with 3–10 items. Dialog enforces 1–20 items.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Section heading; hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Intro below title; hidden when `config.hideDescription` or `config.hideTitle` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `items` | array | sample FAQs | `{ question, answer }` pairs; 1–20 items |
| `instanceId` | string | auto-generated | Unique accordion root id when multiple FAQ sections appear on one page |
| `expandFirst` | boolean | true | Opens first item on load |
| `centerTitle` | boolean | true | Centres title and description |
| `hideTitle` | boolean | false | Hides entire header block |
| `hideDescription` | boolean | false | Hides description only |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### FAQ item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `question` | string | Recommended | Accordion header label |
| `answer` | string (markdown) | Recommended | Body shown when expanded; dialog uses the same markdown editor as **Markdown Text**; rendered with `markdown-to-html`; also copied into FAQPage JSON-LD |

Published output includes a `<script type="application/ld+json">` FAQPage blob (`mainEntity` Question / acceptedAnswer pairs) so search engines can index the Q&A. Empty item lists omit the script.

## Anti-patterns

- More than 15 items without grouping — split into multiple sections or use Markdown Text
- Duplicating pricing tier details already on a **Pricing** (`misc/pricing`) section
- Empty `question` or `answer` strings on published pages
- Multiple FAQ sections on one page without distinct `instanceId` values — accordion ids may collide

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Frequently asked questions",
  "description": "Everything you need to know before getting started."
}
```

**Config:**

```json
{
  "expandFirst": true,
  "centerTitle": true,
  "items": [
    {
      "question": "Is there a free trial?",
      "answer": "Yes — all paid plans include a **14-day** free trial."
    },
    {
      "question": "Can I cancel anytime?",
      "answer": "You can cancel your subscription from account settings at any time."
    },
    {
      "question": "Do you offer team discounts?",
      "answer": "Contact sales for volume pricing on teams of 50 or more."
    }
  ]
}
```
