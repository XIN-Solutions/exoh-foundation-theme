# Embedded Video

**Type:** `content/embedded-video`

## Purpose

Responsive 16:9 YouTube or Vimeo embed in a configurable content width.

## When to use

- Mid-page product demos or talks
- Tutorial or webinar recordings
- Any page section that is primarily a hosted video
- Narrower embed (`columnSize` < 12) within article layout

## When not to use

- Above-the-fold hero with video — use **Video Hero** (`hero/video-hero`) or **Two Column Hero** (`hero/two-col-hero`)
- Background looping video — use **Hero Image** (`hero/hero`)
- Self-hosted MP4 inline player in hero — use **Video Hero** (`hero/video-hero`)

## Key fields and constraints

Set video and layout via **`config`** on **`append_section`** / **`update_section`**. No **`model`** fields.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `video` | string | — | **Required** — YouTube or Vimeo video ID (or parseable URL) |
| `videoType` | string | `youtube` | `youtube` or `vimeo` |
| `columnSize` | string | `12` | Content width (`1`–`12`) |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

Shows warning when `config.video` is empty.

## Anti-patterns

- Empty `video` — renders warning
- Wrong `videoType` for the ID (YouTube ID with `vimeo`)
- Full MP4 file path in `video` — embed expects platform ID
- Multiple redundant video sections back-to-back

## Examples

Pass as `config` argument to **`append_section`** or **`update_section`**.

```json
{
  "video": "dQw4w9WgXcQ",
  "videoType": "youtube",
  "columnSize": "10"
}
```

Vimeo:

```json
{
  "video": "123456789",
  "videoType": "vimeo"
}
```
