# Embedded Video

## Purpose

Responsive 16:9 YouTube or Vimeo embed in a configurable content width. Component name: **Embedded Video** (`partials/sections/content/embedded-video/`). `enableConfig: true`, priority 20.

## When to use

- Mid-page product demos or talks
- Tutorial or webinar recordings
- Any page section that is primarily a hosted video
- Narrower embed (`columnSize` < 12) within article layout

## When not to use

- Above-the-fold hero with video — use **Video Hero** or **Two Column Hero**
- Background looping video — use **Hero Image**
- Self-hosted MP4 inline player in hero — use **Video Hero**

## Key fields and constraints

### Model fields

None — video is configured entirely via `config`.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `video` | string | — | **Required** — YouTube or Vimeo video ID (or parseable URL) |
| `videoType` | string | `youtube` | `youtube` or `vimeo` |
| `columnSize` | string | `12` | Bootstrap width (`1`–`12`) |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

Shows warning alert when `config.video` is empty.

## Anti-patterns

- Empty `video` — renders warning
- Wrong `videoType` for the ID (YouTube ID with `vimeo`)
- Full MP4 file path in `video` — embed expects platform ID
- Multiple redundant video sections back-to-back

## Examples

```json
{
  "config": {
    "video": "dQw4w9WgXcQ",
    "videoType": "youtube",
    "columnSize": "10"
  }
}
```

Vimeo:

```json
{
  "config": {
    "video": "123456789",
    "videoType": "vimeo"
  }
}
```
