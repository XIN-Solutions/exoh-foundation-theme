# Stats

**Type:** `content/stats`

## Purpose

Grid of 2–4 key-number highlights with large value, label, and optional prefix or suffix for SaaS social proof.

## When to use

- Landing pages showing uptime, customer count, or revenue metrics
- Below hero or pricing to reinforce credibility with hard numbers
- Company about pages summarising scale or reach
- Product pages highlighting performance benchmarks

## When not to use

- Individual customer quotes — use **Testimonials** (`misc/testimonials`)
- Partner or client logos — use **Logo Cloud** (`content/logo-cloud`)
- Icon-led benefit columns — use **Icon Banner** (`content/icon-banner`) or **Showcase** (`content/column-showcase`)
- Animated counters or live data feeds — values are static text in v1

## Key fields and constraints

Set section heading via **`model`**. Set stat items and layout via **`config`** on **`append_section`** / **`update_section`**.

Dialog enforces 2–4 stat items. Column count (`config.columns`) controls responsive grid width per stat.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading above stat grid; hidden when `config.hideTitle` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `items` | array | 4 placeholders | Stat entries; 2–4 items |
| `columns` | string | `four` | Grid columns: `two`, `three`, or `four` |
| `centerTitle` | boolean | true | Centres section title |
| `centerStats` | boolean | true | Centres stat value and label within each column |
| `hideTitle` | boolean | false | Hides section title |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Stat item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `value` | string | Recommended | Main number or figure (e.g. `99.9`, `10`, `24`) |
| `label` | string | Recommended | Description below the value (e.g. `Uptime SLA`) |
| `prefix` | string | Optional | Text before value (e.g. `$`) |
| `suffix` | string | Optional | Text after value (e.g. `%`, `K+`, `/7`) |

## Anti-patterns

- More than four stats — grid becomes crowded; split across sections or use **Showcase**
- Long labels that wrap awkwardly under large values — keep labels short
- Mixing unrelated metrics without a section title for context
- Using for non-numeric claims (e.g. full sentences as `value`)
- Duplicating the same stats block already shown in **Pricing** or hero copy on the same page

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Trusted at scale"
}
```

**Config:**

```json
{
  "columns": "four",
  "centerStats": true,
  "items": [
    {
      "value": "99.9",
      "suffix": "%",
      "label": "Uptime SLA"
    },
    {
      "value": "10",
      "suffix": "K+",
      "label": "Active customers"
    },
    {
      "value": "50",
      "suffix": "+",
      "label": "Countries served"
    },
    {
      "value": "24",
      "suffix": "/7",
      "label": "Expert support"
    }
  ]
}
```
