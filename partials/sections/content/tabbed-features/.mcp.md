# Tabbed Features

**Type:** `content/tabbed-features`

## Purpose

Bootstrap tab navigation with switchable feature panels — each tab shows a title, description, and optional image for product deep-dives and capability overviews.

## When to use

- Product pages explaining multiple capabilities without long scroll
- SaaS landing pages with feature categories (security, integrations, analytics, etc.)
- Enterprise marketing sites where visitors self-select topics of interest
- Mid-page sections between hero and pricing or comparison table

## When not to use

- Sequential onboarding steps — use **Process Steps** (`content/process-steps`)
- Expandable Q&A — use **FAQ Accordion** (`content/faq-accordion`)
- Side-by-side feature list with a single image — use **Icons & Image** (`content/icons-and-image`)
- Four-up icon grid without tab switching — use **Showcase** (`content/column-showcase`)

## Key fields and constraints

Set section heading via **`model`**. Set tab items, active tab, and layout via **`config`** on **`append_section`** / **`update_section`**.

Dialog enforces 3–6 tab items. `config.activeTabIndex` (0-based) sets the initially visible panel. Editor preview may not reflect live tab switching — verify on published preview.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading; hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Intro copy below title; hidden when `config.hideDescription` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `items` | array | 4 placeholders | Tab entries; 3–6 items |
| `activeTabIndex` | number | `0` | 0-based index of the tab open on page load |
| `tabStyle` | string | `tabs` | `tabs` (underline) or `pills` (filled buttons) |
| `imagePosition` | string | `right` | `left`, `right`, `below`, or `none` for panel images |
| `centerNav` | boolean | true | Centre-align tab navigation |
| `centerTitle` | boolean | true | Centre section title and description |
| `hideTitle` | boolean | false | Hides section title |
| `hideDescription` | boolean | false | Hides section description |
| `instanceId` | string | auto-generated | Unique DOM id suffix per section instance |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Tab item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `tabLabel` | string | Recommended | Short label shown in tab navigation |
| `title` | string | Recommended | Panel heading |
| `description` | string | Recommended | Panel body copy |
| `imageUrl` | URL | Optional | Panel image; omitted when `imagePosition` is `none` |
| `imageAlt` | string | Optional | Image alt text |

## Anti-patterns

- More than six tabs — split into two sections or use **FAQ Accordion**
- Long paragraphs per tab — keep copy scannable; link to detail pages for depth
- Identical content across tabs — each tab should cover a distinct capability
- Relying on editor inline preview for tab switching — Bootstrap tabs work on published pages; editor may show only the default active panel
- Using for plan comparison — use **Comparison Table** (`content/comparison-table`) or **Pricing** (`misc/pricing`)

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Platform capabilities",
  "description": "Explore the features that power modern teams."
}
```

**Config:**

```json
{
  "tabStyle": "tabs",
  "imagePosition": "right",
  "activeTabIndex": 0,
  "items": [
    {
      "tabLabel": "Automation",
      "title": "Workflow automation",
      "description": "Build multi-step automations without code using our visual builder.",
      "imageUrl": "/assets/img/features/automation.jpg",
      "imageAlt": "Automation workflow diagram"
    },
    {
      "tabLabel": "Security",
      "title": "Enterprise-grade security",
      "description": "SOC 2 compliant with SSO, audit logs, and role-based access control.",
      "imageUrl": "/assets/img/features/security.jpg",
      "imageAlt": "Security dashboard"
    },
    {
      "tabLabel": "Integrations",
      "title": "Connect your stack",
      "description": "Native integrations with Slack, Salesforce, Jira, and 50+ other tools.",
      "imageUrl": "/assets/img/features/integrations.jpg",
      "imageAlt": "Integration logos grid"
    }
  ]
}
```
