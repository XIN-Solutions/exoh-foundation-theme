# Process Steps

**Type:** `content/process-steps`

## Purpose

Numbered or icon-led step sequence for onboarding narratives, "how it works" flows, and product walkthroughs.

## When to use

- Landing pages explaining a simple signup or setup flow
- Product pages showing how customers get value in ordered stages
- Service pages outlining engagement or delivery phases
- Below hero or pricing to reduce friction before conversion

## When not to use

- Chronological company history or roadmap — use **Timeline** (P3) when available
- Unordered feature lists — use **Showcase** (`content/column-showcase`) or **Icon Banner**
- Individual metrics or KPIs — use **Stats** (`content/stats`)
- Deep feature comparisons — use **Comparison table** (`content/comparison-table`)

## Key fields and constraints

Set section heading via **`model`**. Set steps and layout via **`config`** on **`append_section`** / **`update_section`**.

Dialog allows up to 5 step items. Orientation (`horizontal` / `vertical`) and marker style (`number` / `icon`) control layout.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading; hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Intro copy below title; hidden when `config.hideDescription` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `items` | array | `[]` | Step entries; up to 5 items |
| `orientation` | string | `horizontal` | `horizontal` (row) or `vertical` (stacked) |
| `markerStyle` | string | `number` | `number` (auto-indexed) or `icon` (Line Awesome per step) |
| `centerTitle` | boolean | true | Centres section title and description |
| `centerSteps` | boolean | true | Centres step markers and copy within each step |
| `hideTitle` | boolean | false | Hides section title |
| `hideDescription` | boolean | false | Hides section description |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Step item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string | Recommended | Step heading |
| `description` | string | Recommended | Supporting copy for the step |
| `iconClass` | string | Optional | Line Awesome class when `markerStyle` is `icon` (e.g. `la la-check`) |

## Anti-patterns

- More than five steps — split into two sections or use **Timeline**
- Long paragraphs per step — keep descriptions scannable (one or two sentences)
- Mixing numbered and icon markers within one section — use `markerStyle` consistently
- Using for non-sequential content where order does not matter
- Duplicating the same steps already covered in hero or **CTA Band** copy on the same page

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Lorem ipsum dolor sit amet",
  "description": "Lorem ipsum dolor sit amet, consectetur adipiscing elit."
}
```

**Config:**

```json
{
  "orientation": "horizontal",
  "markerStyle": "number",
  "centerSteps": true,
  "items": [
    {
      "title": "Lorem ipsum",
      "description": "Dolor sit amet, consectetur adipiscing elit."
    },
    {
      "title": "Dolor sit amet",
      "description": "Maecenas cursus in lectus ut dignissim."
    },
    {
      "title": "Consectetur elit",
      "description": "Ut enim ad minim veniam, quis nostrud."
    },
    {
      "title": "Adipiscing",
      "description": "Duis aute irure dolor in reprehenderit."
    }
  ]
}
```
