# Portfolio

**Type:** `content/portfolio`

## Purpose

Responsive grid of project or case-study cards with image, category tag, title, description, and CTA link. Uses manually configured project items in v1 — not a live CMS project loader.

## When to use

- Agency, studio, or product marketing pages showcasing selected work
- Case study listings with category labels (branding, web, product, etc.)
- Two- or three-column project card grids
- Curated portfolios where editors pick featured projects manually

## When not to use

- Automatic child-page listings from the site tree — use **Belt** (`misc/belt`)
- Article or blog previews with dates and excerpts — use **Blog Grid** (`content/blog-grid`)
- Image tiles without project metadata — use **Info Tiles** (`content/info-tiles`)
- Live project feed from CMS pages API — out of scope for v1; configure items manually via `config.items`

## Key fields and constraints

Set section heading via **`model`**. Set project cards, column count, and layout via **`config`** on **`append_section`** / **`update_section`**.

v1 uses static `config.items` only. Filter tag chips above the grid are derived from unique project categories when `config.showFilterTags` is true — display only, no client-side filtering.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading; hidden when `config.hideTitle` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `items` | array | sample projects | 2–6 project cards; see item shape below |
| `filterCategories` | array | derived | Unique category labels synced from `items` in the config dialog |
| `columns` | string | `three` | `two` or `three` responsive columns |
| `showFilterTags` | boolean | false | When true, shows a row of category chips above the grid |
| `hideCategory` | boolean | false | When true, hides category badge on individual cards |
| `centerTitle` | boolean | true | Centre-align section heading and filter chips |
| `hideTitle` | boolean | false | Hides section heading |
| `useAltBackground` | boolean | false | Light alternate background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Project item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string | Recommended | Card headline / project name |
| `category` | string | Optional | Category tag (e.g. `Branding`, `Web design`); used for card badge and filter chip row |
| `description` | string | Optional | Short project summary |
| `imageUrl` | URL | Optional | Card image; defaults to empty placeholder |
| `imageAlt` | string | Optional | Image alt text |
| `url` | URL | Optional | Link target for image, title, and CTA |
| `linkText` | string | Optional | CTA label; defaults to `View case study` |

## Anti-patterns

- Expecting automatic project pagination or interactive category filtering — v1 filter chips are display-only
- Fewer than two items — dialog enforces minimum of two cards
- Mismatched image aspect ratios across cards — use consistent ~4:3 project screenshots
- Using for partner logos — use **Logo Cloud** (`content/logo-cloud`)
- Empty `url` with real case studies — always set `url` to the project page

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Our work"
}
```

**Config:**

```json
{
  "columns": "three",
  "showFilterTags": true,
  "filterCategories": ["Branding", "Web design", "Product"],
  "items": [
    {
      "title": "Northwind rebrand",
      "category": "Branding",
      "description": "Identity system and launch assets for a B2B logistics platform.",
      "imageUrl": "/assets/img/portfolio/northwind.jpg",
      "imageAlt": "Northwind brand guidelines spread",
      "url": "/work/northwind-rebrand",
      "linkText": "View case study"
    },
    {
      "title": "Acme commerce platform",
      "category": "Web design",
      "description": "Headless storefront redesign with improved conversion flows.",
      "imageUrl": "/assets/img/portfolio/acme.jpg",
      "imageAlt": "Acme storefront homepage",
      "url": "/work/acme-commerce",
      "linkText": "View case study"
    },
    {
      "title": "Launchpad mobile app",
      "category": "Product",
      "description": "End-to-end product design for a team collaboration app.",
      "imageUrl": "/assets/img/portfolio/launchpad.jpg",
      "imageAlt": "Launchpad mobile screens",
      "url": "/work/launchpad-app",
      "linkText": "View case study"
    }
  ]
}
```
