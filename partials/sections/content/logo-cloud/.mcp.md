# Logo Cloud

**Type:** `content/logo-cloud`

## Purpose

Horizontal row of client or partner logos with optional section heading for trust and social proof.

## When to use

- Below hero or pricing sections to show trusted brands
- Partner or integration pages listing technology alliances
- Landing pages needing a compact logo strip without icon columns
- Pre-sales pages reinforcing credibility before testimonials

## When not to use

- Three icon columns with titles and descriptions — use **Icon Banner** (`content/icon-banner`)
- Text-only brand names without images — use the trusted-by row in **Pricing** (`misc/pricing`)
- Scrolling or animated logo ticker — use **Marquee** (P3, not yet implemented)
- Denser "works with" tool grid — use **Integration logos grid** (P3 variant)

## Key fields and constraints

Set section heading via **`model`**. Set logo items and layout via **`config`** on **`append_section`** / **`update_section`**.

Works best with 4–8 logos. Dialog enforces 4–12 items.

Content images use theme `imageBorderRadius` via global CSS — do not add Bootstrap `rounded` on `<img>` elements.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading above logo row; hidden when `config.hideTitle` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `logos` | array | 6 placeholders | Logo items; 4–12 entries |
| `grayscale` | boolean | true | Renders logos in grayscale; colour on hover when enabled |
| `centerTitle` | boolean | true | Centres section title |
| `hideTitle` | boolean | false | Hides section title |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Logo item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `imageUrl` | string | Recommended | Logo image URL |
| `alt` | string | Recommended | Accessible description; also used as link `aria-label` when `url` is set |
| `url` | string | Optional | When set, logo is wrapped in a link |

## Anti-patterns

- Fewer than 4 logos — dialog enforces minimum; sparse rows look unbalanced
- Mixing wildly different logo aspect ratios without consistent max-height styling
- Using Bootstrap `rounded` on logo `<img>` tags — conflicts with theme image radius ADR
- Duplicating the same trusted-by block already on a **Pricing** section on the same page
- Empty `alt` text on published pages when logos convey brand identity

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Trusted by teams worldwide"
}
```

**Config:**

```json
{
  "grayscale": true,
  "centerTitle": true,
  "logos": [
    {
      "imageUrl": "/media/partners/acme.svg",
      "alt": "Acme Corp",
      "url": "https://acme.example"
    },
    {
      "imageUrl": "/media/partners/globex.svg",
      "alt": "Globex",
      "url": ""
    },
    {
      "imageUrl": "/media/partners/initech.svg",
      "alt": "Initech",
      "url": ""
    },
    {
      "imageUrl": "/media/partners/umbrella.svg",
      "alt": "Umbrella Co",
      "url": ""
    }
  ]
}
```
