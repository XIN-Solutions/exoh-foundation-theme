# Blog Grid

**Type:** `content/blog-grid`

## Purpose

Responsive card grid of article previews with image, title, excerpt, date, and read-more link. Uses manually configured article items in v1 — not a live CMS blog loader.

## When to use

- News, blog, or resources listing sections on marketing pages
- Highlighting 2–6 recent articles with editorial metadata (date, excerpt)
- Two- or three-column article card layouts
- Static curated article lists where editors pick featured posts manually

## When not to use

- Automatic child-page listings from the site tree — use **Belt** (`misc/belt`)
- Single featured article hero — use **Article Hero** (`hero/article-hero`) or **Text & Image** (`content/text-and-image`)
- Image tiles without article metadata — use **Info Tiles** (`content/info-tiles`)
- Live blog feed from CMS pages API — out of scope for v1; configure items manually via `config.items`

## Key fields and constraints

Set section heading via **`model`**. Set article cards, column count, and layout via **`config`** on **`append_section`** / **`update_section`**.

v1 uses static `config.items` only. A future loader that pulls published blog pages is not implemented in this section.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading; hidden when `config.hideTitle` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `items` | array | sample articles | 2–6 article cards; see item shape below |
| `columns` | string | `three` | `two` or `three` responsive columns |
| `hideDate` | boolean | false | When true, hides publication date on cards |
| `centerTitle` | boolean | true | Centre-align section heading |
| `hideTitle` | boolean | false | Hides section heading |
| `useAltBackground` | boolean | false | Light alternate background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Article item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string | Recommended | Card headline |
| `excerpt` | string | Optional | Short summary text |
| `date` | string | Optional | Display date (free text, e.g. `March 4, 2026`); hidden when `config.hideDate` |
| `imageUrl` | URL | Optional | Card image; defaults to empty placeholder |
| `imageAlt` | string | Optional | Image alt text |
| `url` | URL | Optional | Link target for image, title, and CTA |
| `linkText` | string | Optional | CTA label; defaults to `Read more` |

## Anti-patterns

- Expecting automatic blog pagination or category filtering — v1 has no loader; use **Belt** or a future dedicated loader section
- Fewer than two items — dialog enforces minimum of two cards
- Mismatched image aspect ratios across cards — use consistent ~4:3 editorial images
- Using for partner logos — use **Logo Cloud** (`content/logo-cloud`)
- Empty `url` with real articles — always set `url` to the article page

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "From our blog"
}
```

**Config:**

```json
{
  "columns": "three",
  "hideDate": false,
  "items": [
    {
      "title": "How we scaled customer onboarding",
      "excerpt": "Lessons from rolling out self-serve workflows to thousands of teams.",
      "date": "February 10, 2026",
      "imageUrl": "/assets/img/blog/onboarding.jpg",
      "imageAlt": "Team collaborating on onboarding flow",
      "url": "/blog/scaling-onboarding",
      "linkText": "Read article"
    },
    {
      "title": "Security at scale",
      "excerpt": "An overview of our SOC 2 controls and data residency options.",
      "date": "January 22, 2026",
      "imageUrl": "/assets/img/blog/security.jpg",
      "imageAlt": "Security dashboard",
      "url": "/blog/security-at-scale",
      "linkText": "Read article"
    },
    {
      "title": "Product roadmap highlights",
      "excerpt": "What we shipped last quarter and what is coming next.",
      "date": "January 5, 2026",
      "imageUrl": "/assets/img/blog/roadmap.jpg",
      "imageAlt": "Product roadmap sketch",
      "url": "/blog/roadmap-highlights",
      "linkText": "Read article"
    }
  ]
}
```
