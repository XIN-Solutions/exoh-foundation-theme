# Split CTA Form

**Type:** `content/split-cta-form`

## Purpose

Two-column lead-generation block with persuasive copy on one side and a compact inline form on the other — subscribe (name + email) or mini contact (name + email + message).

## When to use

- Landing pages pairing conversion copy with an inline signup or contact form
- Mid-page lead capture where a centred **Subscribe** (`misc/subscribe`) card feels too narrow
- Product pages needing persuasive bullets beside a trial or demo request form
- Campaign pages where copy and form should sit side by side on desktop

## When not to use

- Centred email-only capture without side copy — use **Subscribe** (`misc/subscribe`)
- Full contact page with map embed, phone display, or subject field — use **Contact Form & Map** (`misc/contact-form`)
- Button-only conversion strip without form fields — use **CTA Band** (`content/cta-band`)
- Two-column copy beside an image (no form) — use **Text & Image** (`content/text-and-image`)

## Key fields and constraints

Set headline, description, button label, and optional secondary link via **`model`**. Set form type, column order, field labels, and visibility via **`config`** on **`append_section`** / **`update_section`**.

Subscribe forms post to `model.formAction`; contact forms use the site `/contact` endpoint (same as Contact Form & Map).

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Persuasive headline in the copy column; hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Supporting copy; hidden when `config.hideDescription` |
| `buttonLabel` | string (HTML) | Recommended | Form submit button label |
| `formAction` | URL | Optional | Subscribe form `action` attribute; defaults to `#`; ignored for contact form type |
| `secondaryLinkLabel` | string (HTML) | Optional | Text link below description |
| `secondaryLinkUrl` | URL | Optional | Secondary link destination; defaults to `#` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `formType` | string | `subscribe` | `subscribe` (name + email) or `contact` (name + email + message) |
| `contentPosition` | string | `left` | `left` — copy left, form right; `right` — copy right, form left |
| `nameLabel` | string | `Full name` | Name field label (subscribe) or `Name` (contact) |
| `namePlaceholder` | string | `Jane Smith` | Name input placeholder (subscribe only) |
| `emailLabel` | string | `Email address` | Email field label |
| `emailPlaceholder` | string | `you@company.com` | Email placeholder (subscribe only) |
| `messageLabel` | string | `How can we help?` | Message textarea label (contact only) |
| `privacyNote` | string (HTML) | theme default | Small print below subscribe form; hidden when `config.hidePrivacyNote` |
| `hideTitle` | boolean | false | Hides headline |
| `hideDescription` | boolean | false | Hides description |
| `hideSecondaryLink` | boolean | false | Hides secondary text link |
| `hideName` | boolean | false | Hides name field (subscribe only) |
| `hidePrivacyNote` | boolean | false | Hides privacy note (subscribe only) |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

## Anti-patterns

- `formType: contact` on a newsletter-only page — use Subscribe or set `formType: subscribe`
- `hideName: true` with subscribe form when name is required by your list provider
- Duplicating a full **Contact Form & Map** on the same page — one contact capture block is enough
- Empty `privacyNote` on subscribe forms collecting personal data
- Expecting built-in form submission handling for subscribe — wire `formAction` externally

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model (subscribe):**

```json
{
  "title": "Start your free trial today",
  "description": "Join thousands of teams already using our platform. Get started in minutes — no credit card required.",
  "buttonLabel": "Get started",
  "formAction": "/api/newsletter/subscribe",
  "secondaryLinkLabel": "Compare plans",
  "secondaryLinkUrl": "/pricing"
}
```

**Config (subscribe):**

```json
{
  "formType": "subscribe",
  "contentPosition": "left",
  "emailLabel": "Work email",
  "hideSecondaryLink": false,
  "hidePrivacyNote": false
}
```

**Model (contact):**

```json
{
  "title": "Talk to our team",
  "description": "Tell us about your project and we will get back within one business day.",
  "buttonLabel": "Send message"
}
```

**Config (contact):**

```json
{
  "formType": "contact",
  "contentPosition": "right",
  "messageLabel": "Your message"
}
```
