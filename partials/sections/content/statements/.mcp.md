# Statements

**Type:** `content/statements`

## Purpose

Large image beside a section title and four short statement blocks (title + description pairs).

## When to use

- Key metrics, principles, or differentiators in a 2×2 grid
- About pages with a strong visual and four proof points
- Mid-page sections summarising company values or stats
- Layout with image on left or right

## When not to use

- Three icon columns — use **Showcase** (`content/column-showcase`) or **Icon Banner** (`content/icon-banner`)
- Long prose — use **Markdown Text** (`content/markdown-text`) or **Text & Image** (`content/text-and-image`)
- Photo tiles with CTAs — use **Info Tiles** (`content/info-tiles`)
- Hero placement — use a hero section (`hero/*`)

## Key fields and constraints

Set inline content via **`model`** and layout settings via **`config`** on **`append_section`** / **`update_section`**.

All four statement blocks always render.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Hidden when `config.hideTitle` |
| `statement{N}Title`, `statement{N}Description` | string (HTML) | Optional | N = 1..4 |
| `imageSrc` | URL | Recommended | ~768px wide |
| `imageAlt` | string | Recommended | |
| `imageClass`, `imageId` | string | Optional | |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `imagePosition` | string | `left` | `left` or `right` |
| `hideTitle` | boolean | false | |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Leaving statement slots as placeholder lorem
- Image without `imageAlt`
- Very long `statement{N}Description` — keep statements concise
- Duplicate **Info Tiles** content on the same page

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Built on solid foundations",
  "imageSrc": "/assets/img/office.jpg",
  "imageAlt": "Modern office",
  "statement1Title": "10+ years",
  "statement1Description": "Serving customers across the region.",
  "statement2Title": "500+ clients",
  "statement2Description": "From startups to enterprise.",
  "statement3Title": "24/7 support",
  "statement3Description": "Always here when you need us.",
  "statement4Title": "Local team",
  "statement4Description": "Based in Auckland."
}
```

**Config:**

```json
{
  "imagePosition": "left"
}
```
