# Statements

## Purpose

Large image beside a section title and four short statement blocks (title + description pairs). Component name: **Statements** (`partials/sections/content/statements/`).

## When to use

- Key metrics, principles, or differentiators in a 2×2 grid
- About pages with a strong visual and four proof points
- Mid-page sections summarising company values or stats
- Layout with image on left or right

## When not to use

- Three icon columns — use **Showcase** or **Icon Banner**
- Long prose — use **Markdown Text** or **Text & Image**
- Photo tiles with CTAs — use **Info Tiles**
- Hero placement — use a hero component

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Hidden when `config.hideTitle` |
| `statement{N}Title`, `statement{N}Description` | string (HTML) | Optional | N = 1..4 |
| `imageSrc` | URL | Recommended | ~768px wide |
| `imageAlt` | string | Recommended | |
| `imageClass`, `imageId` | string | Optional | |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `imagePosition` | string | `left` | `left` or `right` |
| `hideTitle` | boolean | false | |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

All four statement blocks always render.

## Anti-patterns

- Leaving statement slots as placeholder lorem
- Image without `imageAlt`
- Very long `statement{N}Description` — keep statements concise
- Duplicate **Info Tiles** content on the same page
