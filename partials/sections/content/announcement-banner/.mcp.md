# Announcement Banner

**Type:** `content/announcement-banner`

## Purpose

Compact dismissible promo strip for time-sensitive announcements — sales, webinars, product launches, or policy updates.

## When to use

- Top-of-page or above-the-fold promo for limited-time offers
- Webinar or event registration reminders on landing pages
- Product launch or feature rollout notices
- Site-wide alerts that should not dominate the page like a full **CTA Band** (`content/cta-band`)

## When not to use

- Mid-page conversion blocks with headline and primary button — use **CTA Band** (`content/cta-band`)
- Persistent site navigation alerts managed globally — use site-level alert chrome
- Long-form promotional copy with multiple CTAs — use **Text & Image** (`content/text-and-image`) or **Split CTA Form** (`content/split-cta-form`)
- Announcements that must stay hidden permanently after dismiss across all visits — v1 dismiss is session-only (see Key fields)

## Key fields and constraints

Set message and optional link via **`model`** (inline edit) or **`config`** (dialog). Set dismiss behaviour, colour variant, and visibility via **`config`** on **`append_section`** / **`update_section`**.

**Dismiss limitation (v1):** When `config.dismissible` is true, closing the banner stores a flag in `sessionStorage` for the current browser tab session. Dismiss is **not** persisted across browser restarts, new tabs, or incognito sessions. Each section instance uses a unique `config.instanceId` for the storage key.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `message` | string (HTML) | Recommended | Promo copy; falls back to `config.message` |
| `linkLabel` | string (HTML) | Optional | CTA link text; falls back to `config.linkLabel` |
| `linkUrl` | URL | Optional | Link destination; falls back to `config.linkUrl`; hidden when `config.hideLink` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `message` | string (HTML) | Promo default | Dialog-editable message; overridden by `model.message` when set |
| `linkLabel` | string | `Learn more` | Dialog-editable link label |
| `linkUrl` | URL | `#` | Dialog-editable link URL |
| `dismissible` | boolean | `true` | Shows close button; session-only dismiss when true |
| `colorVariant` | string | `primary` | `primary`, `alternate`, or `accent` colour band |
| `hideLink` | boolean | `false` | Hides optional link |
| `instanceId` | string | auto-generated | Unique id for dismiss `sessionStorage` key |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `compact` | Section spacing presets |

## Anti-patterns

- Using for primary page hero content — place below the hero or use a hero variant
- Stacking multiple dismissible banners without unique `instanceId` values — dismiss state would collide
- Expecting cross-visit dismiss persistence — not supported in v1; document limitation to editors
- Replacing **CTA Band** for major conversion moments — announcement strip is for short alerts, not full conversion layout
- Very long messages — keep to one or two short sentences for scanability

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "message": "New: AI-powered analytics is now live. <strong>Try it free for 14 days.</strong>",
  "linkLabel": "See what's new",
  "linkUrl": "/product/analytics"
}
```

**Config:**

```json
{
  "dismissible": true,
  "colorVariant": "accent",
  "hideLink": false,
  "instanceId": "launch-analytics-2026"
}
```
