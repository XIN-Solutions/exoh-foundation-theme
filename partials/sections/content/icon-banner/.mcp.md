# Icon Banner

**Type:** `content/icon-banner`

## Purpose

Full-width coloured banner with section title and three centred icon columns (SVG + title + description).

## When to use

- Three key benefits on a branded background strip
- Trust or value pillars below a hero
- Compact icon-led messaging without side images
- Sections needing strong visual separation via theme primary colour

## When not to use

- Four feature columns — use **Showcase** (`content/column-showcase`)
- Icons beside a large image — use **Icons & Image** (`content/icons-and-image`)
- Image tiles with individual CTAs — use **Info Tiles** (`content/info-tiles`)
- Neutral background feature grid — use **Showcase** or **Info Tiles**

## Key fields and constraints

Set inline content via **`model`** and layout settings via **`config`** on **`append_section`** / **`update_section`**.

Background uses theme primary colour from the **`styles`** aspect — not configurable per section.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading above icons |
| `icon{N}Title`, `icon{N}Description` | string (HTML) | Optional | N = 1, 2, 3 |
| `icon{N}Svg` | string (HTML) | Optional | Custom SVG inner HTML |
| `icon{N}ViewBox`, `icon{N}Width`, `icon{N}Height`, `icon{N}StrokeWidth` | — | Optional | SVG attributes |

Default placeholder icons render when `icon{N}Svg` is empty.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Incomplete sets (only one icon filled, others left as lorem)
- Overly large custom SVG markup in `icon{N}Svg`
- Long descriptions — keep to one or two sentences per column
- Using for four or more items — wrong layout

## Examples

Pass as `model` argument to **`append_section`** or **`update_section`**.

```json
{
  "title": "Why customers choose us",
  "icon1Title": "Reliable",
  "icon1Description": "99.9% uptime guaranteed.",
  "icon2Title": "Simple",
  "icon2Description": "No complex setup required.",
  "icon3Title": "Supported",
  "icon3Description": "Local team, fast response."
}
```
