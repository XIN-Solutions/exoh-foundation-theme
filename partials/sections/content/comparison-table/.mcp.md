# Comparison Table

**Type:** `content/comparison-table`

## Purpose

Feature matrix table comparing plans or products across rows, with column headers aligned to Pricing tier naming and per-cell checkmark or text values.

## When to use

- Pricing pages needing a detailed feature matrix below tier cards
- Product comparison pages with 2–4 plan columns
- SaaS landing pages where editors want side-by-side capability checks
- Pages pairing with **Pricing** (`misc/pricing`) for cards plus matrix detail

## When not to use

- Tier cards with prices and CTAs only — use **Pricing** (`misc/pricing`)
- Single conversion strip — use **CTA Band** (`content/cta-band`)
- Unstructured feature lists — use **Showcase** (`content/column-showcase`) or **Icon Banner** (`content/icon-banner`)
- More than four plan columns — layout is optimised for 2–4 columns

## Key fields and constraints

Set header copy via **`model`**. Set plan columns, feature rows, and layout via **`config`** on **`append_section`** / **`update_section`**.

Works best with two to four plan columns and multiple feature rows.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `pretitle` | string (HTML) | Optional | Uppercase label; hidden when `config.hidePretitle` or `config.hideHeader` |
| `title` | string (HTML) | Recommended | Main section heading |
| `description` | string (HTML) | Optional | Subheading below title; hidden when `config.hideDescription` or `config.hideHeader` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `plans` | array | `[]` | Column headers; plan shape matches Pricing (`name`, `subtitle`, `badge`, `highlighted`); up to 4 columns |
| `features` | array | `[]` | Feature rows; see feature shape below |
| `featureColumnLabel` | string | `"Features"` | First-column header text; hidden when `config.hideFeatureColumnLabel` |
| `useAltBackground` | boolean | false | Light alternate background |
| `hideHeader` | boolean | false | Hides entire header block |
| `hidePretitle` | boolean | false | Hides pretitle only |
| `hideDescription` | boolean | false | Hides description only |
| `hideBadge` | boolean | false | Hides plan badge pills in column headers |
| `hideFeatureColumnLabel` | boolean | false | Hides first-column header label |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Plan object shape (column headers)

Matches **Pricing** (`misc/pricing`) tier fields where applicable:

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `name` | string | Recommended | Column header plan name |
| `subtitle` | string | Optional | Smaller text under name |
| `badge` | string | Optional | e.g. `Popular`; hidden when `config.hideBadge` |
| `highlighted` | boolean | false | Highlights entire column |

### Feature row shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `label` | string | Recommended | Row label in first column |
| `cells` | array | Recommended | One cell per plan column; length should match `plans` length |

### Cell object shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `type` | string | Recommended | `check` (default) or `text` |
| `included` | boolean | For `check` | Same semantics as Pricing `features[].included`; shows check or cross icon |
| `value` | string | For `text` | Display text (e.g. `5`, `Unlimited`, `Custom`) |
| `highlighted` | boolean | Optional | Synced from parent plan `highlighted`; used for column styling |

## Anti-patterns

- Mismatched `cells` length vs `plans` length — dialog syncs on save; agents should keep arrays aligned
- Using for price display — this section has no price or CTA fields; pair with **Pricing**
- More than four plans — horizontal scroll works but readability suffers
- Multiple `highlighted: true` plans without intent — only one column should typically stand out
- All text cells when boolean inclusion is clearer — prefer `check` type for yes/no features

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "pretitle": "Lorem ipsum",
  "title": "Lorem ipsum dolor sit amet",
  "description": "Lorem ipsum dolor sit amet, consectetur adipiscing elit."
}
```

**Config:**

```json
{
  "featureColumnLabel": "Features",
  "useAltBackground": false,
  "hideHeader": false,
  "hideBadge": false,
  "plans": [
    { "name": "Lorem", "subtitle": "Lorem ipsum dolor sit amet", "badge": "", "highlighted": false },
    { "name": "Ipsum", "subtitle": "Consectetur adipiscing elit", "badge": "Lorem", "highlighted": true },
    { "name": "Dolor", "subtitle": "Sed do eiusmod tempor", "badge": "", "highlighted": false }
  ],
  "features": [
    {
      "label": "Lorem ipsum",
      "cells": [
        { "type": "text", "value": "5", "highlighted": false },
        { "type": "text", "value": "Ipsum", "highlighted": true },
        { "type": "text", "value": "Ipsum", "highlighted": false }
      ]
    },
    {
      "label": "Dolor sit amet",
      "cells": [
        { "type": "check", "included": true, "highlighted": false },
        { "type": "check", "included": true, "highlighted": true },
        { "type": "check", "included": true, "highlighted": false }
      ]
    },
    {
      "label": "Consectetur elit",
      "cells": [
        { "type": "check", "included": false, "highlighted": false },
        { "type": "check", "included": false, "highlighted": true },
        { "type": "check", "included": true, "highlighted": false }
      ]
    }
  ]
}
```
