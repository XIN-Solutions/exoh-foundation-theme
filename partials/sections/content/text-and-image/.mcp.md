# Text & Image

**Type:** `content/text-and-image`

## Purpose

Two-column section with editable text, optional CTA, and a side image (left or right).

## When to use

- Feature explanations with supporting illustration
- About or service sections mid-page
- Alternating image/text rows (vary `imagePosition` per instance)
- Simple story blocks with a learn-more link

## When not to use

- Above-the-fold hero — use a hero section (`hero/*`)
- Multiple icon feature columns — use **Showcase** (`content/column-showcase`) or **Info Tiles** (`content/info-tiles`)
- Rich markdown body copy — use **Markdown Text** (`content/markdown-text`)
- Four paired statements beside one image — use **Statements** (`content/statements`)

## Key fields and constraints

Set inline content via **`model`** and layout settings via **`config`** on **`append_section`** / **`update_section`**.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Inline HTML fragment only — injected via `innerHTML` into the section's single `<p edit="description innerHTML">` element. Use `<br>` for line breaks, or `<br><br>` between logical paragraphs. Do not wrap in `<p>` tags; the template provides the paragraph element. Hidden when `config.hideDescription` |
| `imageSrc` | URL | Recommended | ~768px wide |
| `imageAlt` | string | Recommended | Accessibility |
| `imageClass` | string | Optional | Default `img-fluid` |
| `learnMoreUrl`, `labelContents` | URL / string | Optional | CTA; hidden when `config.hideCta` |
| `learnMoreClasses`, `learnMoreTitle`, `learnMoreTarget`, `learnMoreRel` | string | Optional | |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `imagePosition` | string | `right` | `left` or `right` |
| `hideTitle`, `hideDescription`, `hideCta` | boolean | false | |
| `useAltBackground` | boolean | false | Alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

## Anti-patterns

- Wrapping `description` in `<p>...</p>` — the template already provides the annotated `<p>` element; outer `<p>` wrappers produce nested or sibling `<p>` elements in the editor DOM (issue #102), breaking inline editing of the description field
- CTA with `labelContents` but `learnMoreUrl: "#"`
- Hiding title, description, and CTA — empty section
- Oversized HTML pasted into `description`
- Using for full-width image galleries — use **Image Gallery** (`content/gallery`)

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Designed for teams",
  "description": "Collaborate in real time with shared workspaces.<br><br>Keep everyone aligned with activity feeds and role-based permissions.",
  "imageSrc": "/assets/img/feature.jpg",
  "imageAlt": "Team collaborating",
  "learnMoreUrl": "/features",
  "labelContents": "Explore features"
}
```

**Config:**

```json
{
  "imagePosition": "left"
}
```
