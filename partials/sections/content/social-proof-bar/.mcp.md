# Social Proof Bar

**Type:** `content/social-proof-bar`

## Purpose

Compact horizontal bar showing aggregate review score, review count, and optional third-party platform badges (G2, Capterra, Trustpilot, etc.).

## When to use

- Homepage or pricing-page trust strip above the fold
- Landing pages citing aggregate ratings from review platforms
- Mid-page credibility between features and pricing
- SaaS sites where a single score is more appropriate than multiple quote cards

## When not to use

- Individual customer quotes with names and photos — use **Testimonials** (`misc/testimonials`)
- Key-number metrics without review context — use **Stats** (`content/stats`)
- Partner or client logos without ratings — use **Image Gallery** (`content/gallery`) or **Info Tiles** (`content/info-tiles`)
- Live review feeds from an API — not supported; content is manual

## Key fields and constraints

Set review count copy via **`model`**. Set rating, badges, and layout via **`config`** on **`append_section`** / **`update_section`**.

Dialog provides aggregate rating (0–max), per-platform badge toggles, and show/hide controls. Review count text is edited inline on the section (`model.reviewText`).

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `reviewText` | string (HTML) | Optional | Review count line; hidden when `config.hideReviewCount` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `rating` | number | `4.8` | Aggregate score displayed as stars and numeric value |
| `maxRating` | number | `5` | `5` (star scale) or `10` (ten-point scale) |
| `badges` | array | 4 platforms | Platform badge entries with `enabled` toggle |
| `centerContent` | boolean | true | Centre-align rating, text, and badges |
| `hideRating` | boolean | false | Hides star row and numeric score |
| `hideReviewCount` | boolean | false | Hides review count text |
| `hideBadges` | boolean | false | Hides platform badge images |
| `useAltBackground` | boolean | false | Light alternate section background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Badge item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `platform` | string | Recommended | Stable id (`g2`, `capterra`, etc.) |
| `label` | string | Recommended | Accessible label and alt text |
| `enabled` | boolean | true | When false, badge is omitted from render |
| `imageUrl` | URL | Recommended | Platform logo or badge image |
| `url` | URL | Optional | Link to review profile; omit for non-linked badge |

## Anti-patterns

- Replacing a testimonials section with only an aggregate score — pair with **Testimonials** or use quotes for depth
- Fabricating ratings — only display verified aggregate scores from real platforms
- Too many badges — keep to 2–4 recognisable platforms; extra logos reduce scanability
- Using for non-review logos — partner logos belong in **Image Gallery** (`content/gallery`) or **Info Tiles** (`content/info-tiles`)
- Expecting automatic sync with G2/Capterra APIs — ratings and counts are manually configured

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "reviewText": "Based on <strong>500+</strong> reviews across G2 and Capterra"
}
```

**Config:**

```json
{
  "rating": 4.8,
  "maxRating": 5,
  "centerContent": true,
  "badges": [
    {
      "platform": "g2",
      "label": "G2",
      "enabled": true,
      "imageUrl": "/assets/img/badges/g2.svg",
      "url": "https://www.g2.com/products/example"
    },
    {
      "platform": "capterra",
      "label": "Capterra",
      "enabled": true,
      "imageUrl": "/assets/img/badges/capterra.svg",
      "url": "https://www.capterra.com/p/example"
    },
    {
      "platform": "trustpilot",
      "label": "Trustpilot",
      "enabled": false,
      "imageUrl": "/assets/img/badges/trustpilot.svg",
      "url": ""
    }
  ]
}
```
