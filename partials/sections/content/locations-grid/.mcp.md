# Locations Grid

**Type:** `content/locations-grid`

## Purpose

Responsive grid of office or branch location cards with address, phone, email, and optional external map link per location. Extends map capability beyond the single embed in **Contact Form & Map** (`misc/contact-form`) by supporting multiple locations with per-office directions links.

## When to use

- Contact or about pages listing regional offices, stores, or service centres
- Multi-location businesses needing address and contact details per branch
- Office finder sections with external map links (Google Maps, Apple Maps, etc.)
- Two- or three-column location card grids

## When not to use

- Single map embed with one contact form — use **Contact Form & Map** (`misc/contact-form`)
- Interactive map with pins and filtering — out of scope for v1; use external map URLs per card
- Team member bios with photos — use **Team** (`misc/team`)
- Generic icon feature grids — use **Showcase** or **Info Tiles**

## Key fields and constraints

Set section heading via **`model`**. Set location cards, column count, and layout via **`config`** on **`append_section`** / **`update_section`**.

Each location card supports an external `mapUrl` (e.g. Google Maps directions link). Map links render only when `config.showMapLinks` is true and the item has a non-empty `mapUrl`. Unlike Contact Form & Map, this section does not embed an iframe map — it links out per office.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Section heading; hidden when `config.hideTitle` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `items` | array | sample offices | 2–6 location cards; see item shape below |
| `columns` | string | `three` | `two` or `three` responsive columns |
| `showMapLinks` | boolean | true | When true, shows map link button on cards that have `mapUrl` |
| `centerTitle` | boolean | true | Centre-align section heading |
| `hideTitle` | boolean | false | Hides section heading |
| `useAltBackground` | boolean | false | Light alternate background |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Location item shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `name` | string | Recommended | Office or branch name |
| `address` | string | Optional | Street address; newlines render as line breaks |
| `phone` | string | Optional | Displayed with `tel:` link |
| `email` | string | Optional | Displayed with `mailto:` link |
| `mapUrl` | URL | Optional | External map or directions URL; shown when `config.showMapLinks` is true |
| `mapLinkText` | string | Optional | Map button label; defaults to `View on map` |

## Anti-patterns

- Expecting a single embedded map for all locations — use per-item `mapUrl` links or Contact Form & Map for one embed
- Fewer than two locations — dialog enforces minimum of two cards
- Using for partner logos or trust strips — use **Logo Cloud** (`content/logo-cloud`)
- Empty contact fields on every card — include at least address or phone for each office
- Relying on map links when `config.showMapLinks` is false — toggle must be enabled

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Visit us"
}
```

**Config:**

```json
{
  "columns": "three",
  "showMapLinks": true,
  "items": [

      "name": "Auckland HQ",
```
