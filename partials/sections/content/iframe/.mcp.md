# Iframe

**Type:** `content/iframe`

## When to use

- Third-party https embeds such as hosted forms or widgets
- Jotform, Typeform, or similar tools that provide a full embed URL
- Full-width or centred embed within page content flow

## When not to use

- YouTube or Vimeo video — use **Embedded Video** (`content/embedded-video`)
- Native site contact flow — use **Contact Form & Map** (`misc/contact-form`)
- Content that should be plain text or markdown — use **Markdown Text** (`content/markdown-text`)

## Key fields and constraints

Set fields via **`config`** on **`append_section`** / **`update_section`**. No **`model`** fields.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `url` | string | `''` | **Required for embed** — full URL; only `https://` URLs render an iframe |
| `minHeight` | string | `600` | Minimum iframe height in pixels, clamped 200–2000 |
| `allow` | string | `''` | Optional iframe `allow` attribute; omitted when empty |
| `columnSize` | string | `12` | `4`, `6`, `8`, `10`, `12`, or `containerless` (edge-to-edge) |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

Shows a warning when `url` is missing or not an `https://` URL.

## Anti-patterns

- `http://` or `javascript:` URLs — not stored or rendered
- Very small `minHeight` for tall forms — increase height so users can scroll inside the frame
- Embedding video platforms — use Embedded Video instead
- Odd `columnSize` values — only even widths and `containerless` are supported

## Examples

Pass as `config` argument to **`append_section`** or **`update_section`**.

```json
{
  "url": "https://form.jotform.com/1234567890",
  "minHeight": "800",
  "columnSize": "10"
}
```

With optional permissions:

```json
{
  "url": "https://example.com/embed",
  "allow": "fullscreen",
  "columnSize": "containerless"
}
```
