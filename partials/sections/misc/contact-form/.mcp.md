# Contact Form & Map

**Type:** `misc/contact-form`

## Purpose

Contact section with editable heading, description, email/phone, optional map embed, and contact form.

## When to use

- Contact or support pages
- Footer-adjacent conversion sections
- Locations with map embed
- Pages needing form + contact details side by side or stacked

## When not to use

- Newsletter signup only — use **Markdown Text** (`content/markdown-text`) for custom HTML if needed
- Team profiles — use **Team** (`misc/team`)
- General content blocks — use **Text & Image** (`content/text-and-image`)
- Multiple forms on one page — one contact section is usually enough

## Key fields and constraints

Set inline content via **`model`** and layout/contact settings via **`config`** on **`append_section`** / **`update_section`**.

Contact email/phone in **`config`** fall back to site-level contact details when unset.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Hidden when `config.hideTitle` |
| `titleId`, `titleClasses` | string | Optional | |
| `description` | string (HTML) | Optional | Hidden when `config.hideDescription` |
| `descriptionId`, `descriptionClasses` | string | Optional | |
| `sendButtonText` | string (HTML) | Optional | Default "Send" |
| `sendButtonClass`, `sendButtonId` | string | Optional | |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `contentPosition` | string | `top` | `top`, `bottom`, `left`, `right` — layout of text vs form |
| `hideTitle`, `hideDescription` | boolean | false | |
| `email`, `phone` | string | — | Shown in content block |
| `hideMap` | boolean | false | |
| `mapPosition` | string | `bottom` | `top` or `bottom` |
| `mapLat`, `mapLon` | string | Auckland defaults | Map embed coordinates |
| `nameLabel`, `emailLabel`, `subjectLabel`, `messageLabel` | string | — | Form field labels |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

Form field names are fixed (`name`, `email`, `subject`, `message`).

## Anti-patterns

- Hiding map and all contact details with empty title/description
- Invalid `mapLat`/`mapLon` — map shows wrong location
- Expecting to customise form fields beyond labels
- Multiple contact sections on one page

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Get in touch",
  "description": "We typically respond within one business day.",
  "sendButtonText": "Send message"
}
```

**Config:**

```json
{
  "email": "hello@example.com",
  "phone": "+64 9 123 4567",
  "contentPosition": "left",
  "mapLat": "-36.8485",
  "mapLon": "174.7633"
}
```

Map hidden:

```json
{
  "config": {
    "hideMap": true,
    "contentPosition": "top"
  }
}
```
