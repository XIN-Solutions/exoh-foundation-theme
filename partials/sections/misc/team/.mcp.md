# Team

## Purpose

Team member grid (1–4 people) with photo, name, role, and bio. Component name: **Team** (`partials/sections/misc/team/`). Style variants: `style3`, `style4`, `style5`.

## When to use

- About or careers pages
- Leadership or department introductions
- 1–4 profile cards with headshots
- Sections needing optional section title and intro

## When not to use

- Customer quotes — use **Testimonials**
- Generic icon features — use **Showcase**
- Dynamic page listings — use **Belt**
- More than four members — add a second section or use **Belt**

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Section intro; hidden when `config.hideDescription` |
| `member{N}Name`, `member{N}Role`, `member{N}Description` | string (HTML) | Optional | N = 1..4 (by column setting) |
| `member{N}ImageSrc`, `member{N}ImageAlt` | URL / string | Optional | Square headshots ~512px |
| `member{N}SocialHtml` | string (HTML) | Optional | Social links (style-dependent) |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `styleVariant` | string | `style3` | `style3`, `style4`, or `style5` |
| `columns` | string | `four` | `one`, `two`, `three`, `four` — controls visible members |
| `hideTitle`, `hideDescription` | boolean | false | |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

Members beyond `columns` count are not rendered.

## Anti-patterns

- `columns: four` with only one member filled
- Missing `member{N}ImageAlt` on photos
- Placeholder “John Doe” left in production
- Using for testimonials — wrong component

## Examples

```json
{
  "title": "Meet our team",
  "description": "The people behind the product.",
  "member1Name": "Alex Morgan",
  "member1Role": "CEO",
  "member1Description": "20 years in the industry.",
  "member1ImageSrc": "/assets/img/team/alex.jpg",
  "member1ImageAlt": "Alex Morgan",
  "member2Name": "Sam Lee",
  "member2Role": "CTO",
  "member2Description": "Leads engineering and product.",
  "member2ImageSrc": "/assets/img/team/sam.jpg",
  "member2ImageAlt": "Sam Lee",
  "config": {
    "styleVariant": "style3",
    "columns": "two"
  }
}
```
