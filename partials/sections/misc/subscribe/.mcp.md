# Subscribe

**Type:** `misc/subscribe`

## Purpose

Newsletter or mailing-list signup block with headline, description, labelled email field, submit button, and optional privacy note inside a rounded card with decorative pattern.

## When to use

- Footer-adjacent or mid-page email capture on marketing pages
- Blog or content pages inviting newsletter signups
- Landing pages with a single conversion action after feature sections
- Pages needing a compact subscription UI without full **Pricing** (`misc/pricing`) tables

## When not to use

- Plan comparison or paid tiers — use **Pricing** (`misc/pricing`)
- Knowledge-base search — use **KB Search** (`knowledge/search`)
- Long-form content — use **Markdown** (`text/markdown`)
- Primary above-fold hero CTAs — use **Large Hero** (`heroes/large_hero`) with built-in CTA fields
- Two-column persuasive copy plus inline form — use **Split CTA with form** (`content/split-cta-form`)

## Key fields and constraints

Set headline and CTA copy via **`model`**. Set form labels, privacy text, and layout via **`config`** on **`append_section`** / **`update_section`**.

Wire `formAction` to your list provider endpoint; the theme does not handle submission logic.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Section heading |
| `description` | string (HTML) | Optional | Supporting copy; hidden when `config.hideDescription` |
| `buttonLabel` | string (HTML) | Recommended | Submit button label; hidden when `config.hideButton` |
| `formAction` | URL | Optional | Form `action` attribute; defaults to `#` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `emailLabel` | string | `Email address` | Visible label above the email input |
| `emailPlaceholder` | string | `you@company.com` | Email input placeholder |
| `privacyNote` | string (HTML) | theme default | Small print below the form; hidden when `config.hidePrivacyNote` |
| `columnSize` | string | `8` | Card width within container (`6`, `8`, `10`, or `12`) |
| `hidePattern` | boolean | false | Hides decorative background pattern |
| `hideDescription` | boolean | false | Hides description paragraph |
| `hideForm` | boolean | false | Hides entire form (input + button) |
| `hideEmailInput` | boolean | false | Hides email field only |
| `hideButton` | boolean | false | Hides submit button only |
| `hidePrivacyNote` | boolean | false | Hides privacy note |
| `useAltBackground` | boolean | false | Light alternate background on the section |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

## Anti-patterns

- `hideForm: true` on a page whose only goal is signup — leaves title with no action
- `hideEmailInput: true` with `hideButton: false` — button with no input field
- Expecting built-in double opt-in or API integration — configure `formAction` externally
- Placing multiple Subscribe sections on one page — one capture block is usually enough
- Empty `privacyNote` on pages collecting personal data — keep a clear consent or unsubscribe statement

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "title": "Stay in the loop",
  "description": "Monthly product updates and release notes. No spam.",
  "buttonLabel": "Subscribe",
  "formAction": "/api/newsletter/subscribe"
}
```

**Config:**

```json
{
  "emailLabel": "Work email",
  "emailPlaceholder": "you@company.com",
  "privacyNote": "We respect your privacy. Unsubscribe at any time.",
  "columnSize": "8",
  "hidePattern": false,
  "hideDescription": false,
  "hideForm": false,
  "hideEmailInput": false,
  "hideButton": false,
  "hidePrivacyNote": false,
  "useAltBackground": false
}
```
