# Testimonials

## Purpose

Customer quote cards with author name, role, and photo in a 1–4 column grid. Component name: **Testimonials** (`partials/sections/misc/testimonials/`). `enableConfig: true`. Defaults provided in `.content.json`.

## When to use

- Social proof on homepage or landing pages
- Case study highlights with attributed quotes
- 1–4 testimonial tiles with headshots
- Mid-page trust sections below features

## When not to use

- Team member bios — use **Team**
- Generic feature icons — use **Showcase**
- Long unquoted prose — use **Markdown Text**
- Dynamic reviews from a data source — not supported; content is manual

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Optional | Hidden when `config.hideTitle` |
| `description` | string (HTML) | Optional | Section intro; hidden when `config.hideDescription` |
| `testimonial{N}Text` | string (HTML) | Optional | Quote body |
| `testimonial{N}Author` | string (HTML) | Optional | |
| `testimonial{N}Role` | string (HTML) | Optional | Company or job title |
| `testimonial{N}ImageSrc`, `testimonial{N}ImageAlt` | URL / string | Optional | Round headshot ~512px |
| `testimonial{N}QuoteSvg` | string (HTML) | Optional | Custom quote mark SVG |

N = 1..4 depending on `config.columns`.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `columns` | string | `four` | `one`, `two`, `three`, `four` |
| `hideTitle`, `hideDescription` | boolean | false | |
| `useAltBackground` | boolean | false | |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | |

`.content.json` includes full `defaults` for all four testimonials (lorem placeholders).

## Anti-patterns

- Shipping default lorem quotes from `.content.json` defaults
- `columns: four` with only one real testimonial
- Missing author attribution on quotes
- Very long `testimonial{N}Text` — keep quotes scannable

## Examples

```json
{
  "title": "What our customers say",
  "description": "Trusted by teams across New Zealand.",
  "testimonial1Text": "This platform transformed how we work.",
  "testimonial1Author": "Jane Smith",
  "testimonial1Role": "Operations Manager, Acme Ltd",
  "testimonial1ImageSrc": "/assets/img/testimonials/jane.jpg",
  "testimonial1ImageAlt": "Jane Smith",
  "testimonial2Text": "Setup took less than a day.",
  "testimonial2Author": "Tom Brown",
  "testimonial2Role": "Founder, Startup Co",
  "testimonial2ImageSrc": "/assets/img/testimonials/tom.jpg",
  "config": {
    "columns": "two"
  }
}
```
