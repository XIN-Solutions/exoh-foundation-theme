# Belt

## Purpose

Dynamic listing of child pages loaded via the `pages` loader — rendered as horizontal rows, alternating rows, or 3/4-column tile grids. Component name: **Belt** (`partials/sections/misc/belt/`). `enableConfig: true`, priority 10.

## When to use

- “Latest news” or blog roll from a parent page’s children
- Service or product index sections driven by site structure
- Related pages below main content
- Any listing where items come from the page tree, not manual model fields

## When not to use

- Manually authored cards — use **Info Tiles**
- Static icon features — use **Showcase**
- Team member profiles — use **Team**
- Testimonials — use **Testimonials**

## Key fields and constraints

### Model fields

Agents do **not** set listing items in the model. Items come from the loader.

### Loader: `children`

| Output | Source |
|--------|--------|
| `data.children` | Array of child pages from `pages` loader |
| `data.childrenMeta.error` | Set when source page slug is invalid |

Loader params (driven by `config`):

| Config key | Effect |
|------------|--------|
| `basePageSlug` | Parent page slug to list children from; empty uses current page |
| `searchType` | `immediate` (direct children) or `all` (deep descendants) |
| `sort` | e.g. `-publishDate`, `childOrdering` (immediate only) |
| `limit` | Max results; `0` = all |
| `displayType` | `horizontal`, `horizontal_alt`, `3col`, `4col` |

Each tile uses child page SEO/general fields: `metaTitle`/`name`, `description`, `image`/`thumbnail`, `url`. Fallback image: `config.defaultImage`.

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `displayType` | string | `horizontal` | Layout variant |
| `basePageSlug` | string | — | Source page; blank = current page |
| `searchType` | string | — | `immediate` or `all` |
| `sort` | string | `-publishDate` | Child order options when `immediate` |
| `limit` | number | `1000` | `0` = unlimited |
| `ctaLabel` | string | `Read more` | Button text per tile |
| `defaultImage` | URL | `/assets/img/empty.png` | When child has no image |
| `useAltBackground` | boolean | false | |
| `spacing` | string | `comfortable` | |

## Anti-patterns

- Invalid `basePageSlug` — shows error alert (`INVALID_SLUG`)
- `sort: childOrdering` with `searchType: all` (reset to `-publishDate` in editor)
- Expecting to set individual tile text in the section model
- Empty parent with no children — shows “No child pages found”

## Examples

```json
{
  "config": {
    "basePageSlug": "blog",
    "searchType": "immediate",
    "sort": "-publishDate",
    "limit": 6,
    "displayType": "3col",
    "ctaLabel": "Read article"
  }
}
```

Current-page children:

```json
{
  "config": {
    "displayType": "horizontal",
    "limit": 4
  }
}
```
