# Belt

**Type:** `misc/belt`

## Purpose

Dynamic listing of child pages — rendered as horizontal rows, alternating rows, or 3/4-column tile grids. Tile content is loaded from child pages — not set in **`model`**.

## When to use

- "Latest news" or blog roll from a parent page's children
- Service or product index sections driven by site structure
- Related pages below main content
- Any listing where items come from the page tree, not manual model fields

## When not to use

- Manually authored cards — use **Info Tiles** (`content/info-tiles`)
- Static icon features — use **Showcase** (`content/column-showcase`)
- Team member profiles — use **Team** (`misc/team`)
- Testimonials — use **Testimonials** (`misc/testimonials`)

## Key fields and constraints

Set loader parameters and layout via **`config`** on **`append_section`** / **`update_section`**.

Agents do **not** set listing items in **`model`** — tiles are resolved from child pages based on **`config`** loader settings.

### Model fields

None — tile content comes from loaded child pages.

### Config fields (loader and layout)

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `displayType` | string | `horizontal` | `horizontal`, `horizontal_alt`, `3col`, `4col` |
| `basePageSlug` | string | — | Parent page slug to list children from; blank = current page |
| `searchType` | string | — | `immediate` (direct children) or `all` (deep descendants) |
| `sort` | string | `-publishDate` | e.g. `-publishDate`, `childOrdering` (immediate only) |
| `limit` | number | `1000` | `0` = unlimited |
| `ctaLabel` | string | `Read more` | Button text per tile |
| `defaultImage` | URL | theme default | When child page has no image |
| `useAltBackground` | boolean | false | |
| `spacing` | string | `comfortable` | |

Each tile uses child page SEO/general fields: title, description, image, URL. Invalid `basePageSlug` renders an error state.

## Anti-patterns

- Invalid `basePageSlug` — section shows an error when the parent page does not exist
- `sort: childOrdering` with `searchType: all` — use `-publishDate` instead
- Expecting to set individual tile text in **`model`**
- Empty parent with no children — shows "No child pages found"

## Examples

Pass as `config` argument to **`append_section`** or **`update_section`**.

```json
{
  "config": {
    "basePageSlug": "blog",
    "searchType": "immediate",
    "sort": "-publishDate",
    "limit": 6,
    "displayType": "3col",
    "ctaLabel": "Read article"
  }
}
```

Current-page children:

```json
{
  "config": {
    "displayType": "horizontal",
    "limit": 4
  }
}
```
