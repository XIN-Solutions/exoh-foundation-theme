# Belt

**Type:** `misc/belt`

## Purpose

Dynamic listing of child pages — rendered as horizontal rows, alternating rows, or 3/4-column tile grids. Tile content is loaded from child pages — not set in **`model`**.

## When to use

- "Latest news" or blog roll from a parent page's children
- Service or product index sections driven by site structure
- Related pages below main content
- Any listing where items come from the page tree, not manual model fields

## When not to use

- Manually authored cards — use **Info Tiles** (`content/info-tiles`)
- Static icon features — use **Showcase** (`content/column-showcase`)
- Team member profiles — use **Team** (`misc/team`)
- Testimonials — use **Testimonials** (`misc/testimonials`)

## Key fields and constraints

Set loader parameters and layout via **`config`** on **`append_section`** / **`update_section`**.

Agents do **not** set listing items in **`model`** — tiles are resolved from child pages based on **`config`** loader settings.

### Model fields

None — tile content comes from loaded child pages.

### Config fields (loader and layout)

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `displayType` | string | `horizontal` | `horizontal`, `horizontal_alt`, `3col`, `4col` |
| `basePageSlug` | string | — | Parent page slug to list children from; blank = current page |
| `searchType` | string | *(immediate)* | Omitted or `immediate`: **direct children only**. `all`: all descendants (deep tree). |
| `sort` | string | `-publishDate` | e.g. `-publishDate`, `childOrdering` (immediate only; see below) |
| `limit` | number | `1000` | `0` = unlimited |
| `ctaLabel` | string | `Read more` | Button text per tile |
| `defaultImage` | URL | theme default | Tile image when the child has no usable thumbnail URL |
| `useAltBackground` | boolean | false | |
| `spacing` | string | `comfortable` | |

Invalid `basePageSlug` renders an error state.

### Which pages appear in the belt

The pages loader loads candidates under the base page (see **`searchType`**). Pages where **`general.hideInLists`** is `true` are **excluded** from the belt and from sibling listings that use the same filter. Set or clear that field on the **child page** via the **`general`** aspect (`update_aspect`), not in belt **`config`**.

### Sorting and `childOrdering`

With **`searchType`** omitted or `immediate`, **`sort: childOrdering`** (or **`-childOrdering`**) orders tiles by the **listing parent** page’s **`child_ordering`** aspect: field **`orderedChildIds`** (array of child page IDs). Only **direct children** of the base page should appear in that array. If **`orderedChildIds`** is missing or empty, tiles fall back to **name** order. **`childOrdering`** is not valid with **`searchType: all`** — use date or name sorts instead.

### Per-tile field resolution (child pages)

Each tile is built from the loaded child page’s aspects (not belt **`model`**):

| Tile field | Resolution (first non-empty wins) |
|------------|-----------------------------------|
| Title | `general.pageTitle` → `seo.metaTitle` → page **`name`** (empty **`pageTitle`** falls through) |
| Description | `general.description` → `seo.metaDescription` |
| Image | `general.image` → `seo.thumbnail` (media object); rendering uses **`thumbnail.url`** — without a **`url`**, the belt uses **`config.defaultImage`** or the theme empty placeholder |
| Link | Child page public URL |

## Anti-patterns

- Invalid `basePageSlug` — section shows an error when the parent page does not exist
- `sort: childOrdering` with `searchType: all` — use `-publishDate` or another sort instead
- Expecting to set individual tile text in **`model`**
- Hiding a page from the belt only in section config — use **`general.hideInLists`** on the child page
- Empty parent with no children — shows "No child pages found"

## Examples

Pass as `config` argument to **`append_section`** or **`update_section`**.

```json
{
  "config": {
    "basePageSlug": "blog",
    "searchType": "immediate",
    "sort": "-publishDate",
    "limit": 6,
    "displayType": "3col",
    "ctaLabel": "Read article"
  }
}
```

Current-page children:

```json
{
  "config": {
    "displayType": "horizontal",
    "limit": 4
  }
}
```

Manual child order on the parent (parent must have **`child_ordering.orderedChildIds`** populated):

```json
{
  "config": {
    "basePageSlug": "services",
    "searchType": "immediate",
    "sort": "childOrdering",
    "displayType": "4col",
    "limit": 12
  }
}
```
