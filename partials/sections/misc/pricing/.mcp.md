# Pricing

**Type:** `misc/pricing`

## Purpose

Branded pricing table with plan cards, per-tier feature lists, optional highlighted plan, trusted-by brand row, and currency disclaimer footer.

## When to use

- Dedicated pricing or plans pages (`/pricing`)
- Conversion-focused landing pages comparing tiers
- SaaS or subscription products with 2–3 plan columns
- Pages needing social proof via a trusted-by brand row

## When not to use

- Single CTA newsletter blocks — use **Subscribe** (`misc/subscribe`)
- Feature explanations without prices — use **Showcase** (`content/column-showcase`) or **Icon Banner** (`content/icon-banner`)
- Plan feature matrices without prices — use **Comparison table** (`content/comparison-table`) after pricing schema is in place
- Dynamic product catalogues — use **Belt** (`misc/belt`)

## Key fields and constraints

Set header copy via **`model`**. Set plans, brands, and layout via **`config`** on **`append_section`** / **`update_section`**.

Grid works best with two or three plans.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `pretitle` | string (HTML) | Optional | Uppercase label; hidden when `config.hidePretitle` or `config.hideHeader` |
| `title` | string (HTML) | Recommended | Main section heading |
| `description` | string (HTML) | Optional | Subheading below title; hidden when `config.hideDescription` or `config.hideHeader` |
| `trustedByLabel` | string (HTML) | Optional | Label above brand row; hidden when `config.hideTrustedByLabel` or `config.hideTrustedBy` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `plans` | array | sample plans | Plan cards; see plan shape below |
| `trustedBy` | array | sample brands | `{ name, url }` entries for bottom brand row |
| `currency` | string | `""` | ISO code (`USD`, `EUR`, etc.) — shows bottom disclaimer when set; does not format prices |
| `useAltBackground` | boolean | false | Light alternate background instead of primary colour band |
| `hideHeader` | boolean | false | Hides entire header block |
| `hidePretitle` | boolean | false | Hides pretitle only |
| `hideDescription` | boolean | false | Hides description only |
| `hideBadge` | boolean | false | Hides plan badge pills |
| `hidePriceSuffix` | boolean | false | Hides `/mo`-style suffix on all plans |
| `hideTrustedBy` | boolean | false | Hides entire trusted-by block |
| `hideTrustedByLabel` | boolean | false | Hides label above brand names |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Section spacing presets |

### Plan object shape

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `name` | string | Recommended | Plan name |
| `subtitle` | string | Optional | Short tagline under name |
| `price` | string | Recommended | Display price (free text, e.g. `$79`) |
| `priceSuffix` | string | Optional | e.g. `/mo`; hidden when `config.hidePriceSuffix` |
| `badge` | string | Optional | Corner badge (e.g. `Popular`); hidden when `config.hideBadge` |
| `highlighted` | boolean | false | Emphasises card with accent border |
| `ctaLabel` | string | Recommended | Button text |
| `ctaUrl` | URL | Recommended | Button link; defaults to `#` |
| `features` | array | Recommended | `{ label, included }` items; `included: false` shows blocked icon |

## Anti-patterns

- More than three plans without checking layout — grid is three columns on large screens
- Multiple `highlighted: true` plans — only one should stand out
- `ctaLabel` set with empty or `#` `ctaUrl` on published pages
- Relying on `currency` to format prices — it only adds a footer disclaimer
- Hiding header (`hideHeader: true`) while leaving empty `plans` — users see cards with no context
- Using on every page — reserve for pricing-focused conversion paths

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "pretitle": "Plans",
  "title": "Simple, transparent pricing",
  "description": "Start free and scale as you grow.",
  "trustedByLabel": "Trusted by teams at"
}
```

**Config:**

```json
{
  "currency": "USD",
  "useAltBackground": false,
  "hideHeader": false,
  "hideBadge": false,
  "hidePriceSuffix": false,
  "hideTrustedBy": false,
  "plans": [
    {
      "name": "Starter",
      "subtitle": "For small teams",
      "price": "$29",
      "priceSuffix": "/mo",
      "badge": "",
      "highlighted": false,
      "ctaLabel": "Get started",
      "ctaUrl": "/signup/starter",
      "features": [
        { "label": "5 projects", "included": true },
        { "label": "Email support", "included": true },
        { "label": "SSO", "included": false }
      ]
    },
    {
      "name": "Growth",
      "subtitle": "Most popular",
      "price": "$79",
      "priceSuffix": "/mo",
      "badge": "Popular",
      "highlighted": true,
      "ctaLabel": "Start trial",
      "ctaUrl": "/signup/growth",
      "features": [
        { "label": "Unlimited projects", "included": true },
        { "label": "Priority support", "included": true },
        { "label": "Advanced analytics", "included": true }
      ]
    }
  ],
  "trustedBy": [
    { "name": "ACME_CO", "url": "https://example.com" },
    { "name": "BETA_LABS", "url": "https://example.com" }
  ]
}
```
