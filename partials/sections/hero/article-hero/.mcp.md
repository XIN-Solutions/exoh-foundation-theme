# Article Hero

**Type:** `hero/article-hero`

## Purpose

Article header with optional ancestor breadcrumb, background image, category tag, two-line title (with accent line), and metadata row (date, read time, author).

## When to use

- Blog posts, news articles, and knowledge-base article pages
- Content pages where the hero must show publication metadata
- Article above-the-fold with a mood-setting background image behind the title

## When not to use

- Marketing landing pages with CTAs — use **Hero Image** (`hero/hero`) or **Image Banner** (`hero/image-banner`)
- Hub or index pages without article metadata — use **Image Banner** (`hero/image-banner`)
- Mid-page content — use **Markdown Text** (`content/markdown-text`) or **Text & Image** (`content/text-and-image`)
- Second hero on the same page — pick one hero variant only

## Key fields and constraints

Set inline content via **`model`** and layout/visibility settings via **`config`** on **`append_section`** / **`update_section`**.

### Breadcrumb

The breadcrumb is loaded via a section **`page`** loader (`breadcrumbPage` in `.content.json`) for the current page — not from `model` / `config` fields you set via MCP, and not from global section context.

**When it appears:** when the loader returns a non-empty `ancestors` array and `config.hideBreadcrumb` is not `true`. Root pages (no ancestors) omit the breadcrumb entirely.

**Trail rules:**

- Items run from site root through each parent page, then the current page as the final (leaf) item
- The site-root crumb is a **home** icon (accessible label "Home"), not the site name
- Other ancestor items link to their page `url` with labels `navLabel` when present, otherwise `name`
- The current page is plain text (not linked)
- Placement is below the tag badge (when shown) and above the title

Agents cannot set ancestors via **`append_section`** / **`update_section`**; use `hideBreadcrumb` to suppress the trail when needed.

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `tag` | string (HTML) | Optional | Category or topic badge above the title; hidden when `config.hideTag` |
| `title` | string (HTML) | Recommended | Primary headline (first line of `<h1>`) |
| `titleAccent` | string (HTML) | Optional | Accent-coloured second line of the headline; hidden when `config.hideTitleAccent` |
| `publishedAt` | string (HTML) | Optional | Date label in the metadata row; hidden when `config.hideMeta` |
| `readTime` | string (HTML) | Optional | Read-time label (e.g. "5 min read"); hidden when `config.hideMeta` |
| `author` | string (HTML) | Optional | Author name; hidden when `config.hideMeta` |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `backgroundImage` | URL | theme default | Background image behind the article heading |
| `backgroundImageAlt` | string | — | Alt text for the background image (accessibility) |
| `hideBreadcrumb` | boolean | false | Hides the ancestor breadcrumb trail below the tag |
| `hideTag` | boolean | false | Hides the category/tag badge |
| `hideMeta` | boolean | false | Hides the date, read time, and author row |
| `hideTitleAccent` | boolean | false | Hides the accent-coloured second headline line |
| `hideOverlay` | boolean | false | Hides the tint overlay over the background image |
| `overlayColour` | string | `#000000` | Tint colour when overlay is shown |
| `overlayOpacity` | number | `0.7` | Tint opacity when overlay is shown |
| `spacing` | string | `comfortable` | Section spacing |
| `noTopSpacing`, `noBottomSpacing` | boolean | false | |

## Anti-patterns

- Using on non-article pages where metadata fields would be filler text
- Leaving `backgroundImageAlt` empty when a custom `backgroundImage` is set — provide descriptive alt text
- Stacking **Article Hero** with **Hero Image** on the same page
- Very long `title` / `titleAccent` — article heroes work best with concise headlines
- Hiding both `tag` and `meta` on an article page with no other context above the fold
- Setting `hideBreadcrumb: true` on nested pages where the trail is redundant with other navigation

## Examples

Pass as `model` and `config` arguments to **`append_section`** or **`update_section`**.

**Model:**

```json
{
  "tag": "Lorem ipsum",
  "title": "Lorem ipsum dolor sit amet",
  "titleAccent": "Consectetur adipiscing elit.",
  "publishedAt": "March 12, 2026",
  "readTime": "6 min read",
  "author": "Lorem Ipsum"
}
```

**Config:**

```json
{
  "backgroundImage": "/assets/images/bgs/article-hero.jpg",
  "backgroundImageAlt": "Abstract blue gradient background",
  "hideBreadcrumb": false,
  "hideTag": false,
  "hideMeta": false
}
```
