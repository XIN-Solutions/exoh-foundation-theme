# Hero Image

## Purpose

Full-width hero banner with centred headline, subtitle, and CTA over a background image or video. Component name: **Hero Image** (`partials/sections/hero/hero/`).

## When to use

- Homepage or landing-page above-the-fold hero
- Single primary message with one CTA
- Background photo or looping video behind text
- Pages needing optional decorative top/bottom separators

## When not to use

- Side-by-side text and image layout — use **Two Column Hero**
- Inline playable video in the hero body — use **Video Hero**
- Mid-page content blocks — use **Text & Image** or **Markdown Text**
- Second hero on the same page — pick one hero variant only

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Hidden when `config.hideTitle` |
| `titleId`, `titleClass` | string | Optional | DOM id / CSS classes |
| `description` | string (HTML) | Optional | Rendered as `<h2>`; hidden when `config.hideSubtitle` |
| `descriptionId`, `descriptionClass` | string | Optional | |
| `buttonUrl` | URL | Optional | Required with `buttonLabel` for a working CTA |
| `buttonLabel` | string (HTML) | Optional | Hidden when `config.hideButton` |
| `buttonId`, `buttonClasses`, `buttonTitle`, `buttonTarget` | string | Optional | Link attributes |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `compact` | boolean | false | Shorter hero height |
| `spacing` | string | `comfortable` | Section vertical spacing |
| `noTopSpacing`, `noBottomSpacing` | boolean | false | Remove edge spacing |
| `hideTitle`, `hideSubtitle`, `hideButton` | boolean | false | Toggle content blocks |
| `hideOverlay` | boolean | false | When false, dark overlay on background |
| `overlayColour` | string | `#000000` | CSS colour |
| `overlayOpacity` | number | `0.7` | 0–1 |
| `backgroundImage` | URL | — | Wide image (~1920px); poster when video set |
| `backgroundVideo` | URL | — | Looped muted autoplay video; takes precedence over image |
| `setHeroSeparators` | boolean | false | Decorative SVG separators |
| `separatorPairBase`, `separatorTopId`, `separatorBottomId` | string | — | Separator shape ids |
| `separatorDifferentTopBottom`, `reduceSeparator` | boolean | false | Separator layout options |

## Anti-patterns

- CTA with `buttonLabel` but empty `buttonUrl`
- Background video without `backgroundImage` poster (poor load experience)
- Stacking multiple hero sections on one page
- Very long `title`/`description` — hero is for a short headline
- Setting both `hideTitle` and `hideSubtitle` with no visual focal point

## Examples

```json
{
  "title": "Build something great",
  "description": "A short supporting line for the main headline.",
  "buttonUrl": "/get-started",
  "buttonLabel": "Get started",
  "config": {
    "backgroundImage": "/assets/img/hero.jpg",
    "overlayOpacity": 0.6
  }
}
```

With video background:

```json
{
  "config": {
    "backgroundVideo": "/assets/video/hero-loop.mp4",
    "backgroundImage": "/assets/img/hero-poster.jpg"
  }
}
```
