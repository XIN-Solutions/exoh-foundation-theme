# Video Hero

## Purpose

Centred headline, subtitle, CTA, and an inline self-hosted video player with decorative background. Component name: **Video Hero** (`partials/sections/hero/video-hero/`).

## When to use

- Product demos or brand films as the focal point
- Homepage hero where the video is the main visual (not background)
- Pages promoting a single video asset with supporting copy

## When not to use

- Background looping video behind text — use **Hero Image** or **Image Banner**
- YouTube/Vimeo embed only — use **Embedded Video**
- Side-by-side layout — use **Two Column Hero**
- Mid-page video block — use **Embedded Video**

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Hidden when `config.hideTitle` |
| `subtitle` | string (HTML) | Optional | Hidden when `config.hideSubtitle` |
| `buttonUrl`, `buttonLabel` | URL / string | Optional | Hidden when `config.hideButton` |
| `buttonClasses`, `buttonTitle`, `buttonTarget`, `buttonRel` | string | Optional | |
| `videoSrc` | URL | Recommended | Self-hosted MP4; default theme sample if unset |
| `posterSrc` | URL | Optional | Video poster frame |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `spacing` | string | `comfortable` | |
| `noTopSpacing`, `noBottomSpacing` | boolean | false | |
| `hideTitle`, `hideSubtitle`, `hideButton`, `hideVideo` | boolean | false | |

Background image is fixed in the template (`/assets/img/background.svg`); not configurable via model.

## Anti-patterns

- YouTube/Vimeo URLs in `videoSrc` — use direct MP4 or **Embedded Video**
- Hiding video (`hideVideo`) with no other visual content
- CTA with label but no `buttonUrl`
- Very large unoptimised video files (slow LCP)

## Examples

```json
{
  "title": "See it in action",
  "subtitle": "A two-minute overview of the platform.",
  "buttonUrl": "/signup",
  "buttonLabel": "Start free trial",
  "videoSrc": "/assets/video/demo.mp4",
  "posterSrc": "/assets/img/demo-poster.jpg"
}
```
