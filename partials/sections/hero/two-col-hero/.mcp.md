# Two Column Hero

## Purpose

Hero with text in one column and an image (or YouTube lightbox thumbnail) in the other, over a full-width background image. Component name: **Two Column Hero** (`partials/sections/hero/two-col-hero/`).

## When to use

- Homepage hero with product screenshot or team photo beside copy
- Video teaser via YouTube URL and poster image
- When text and visual need equal prominence
- Optional decorative separators at hero edges

## When not to use

- Centred-only headline over background — use **Hero Image** or **Image Banner**
- Self-hosted inline video player — use **Video Hero**
- Mid-page two-column content — use **Text & Image**
- Image-only banner with no side column — use **Image Banner**

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Hidden when `config.hideTitle` |
| `titleId`, `titleClass` | string | Optional | |
| `description` | string (HTML) | Optional | Rendered as `<p>`; hidden when `config.hideSubtitle` |
| `descriptionId`, `descriptionClass` | string | Optional | |
| `buttonUrl`, `buttonLabel` | URL / string | Optional | Hidden when `config.hideButton` |
| `buttonId`, `buttonClasses`, `buttonTitle`, `buttonTarget` | string | Optional | |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `imageColumnPosition` | string | `right` | `left`, `right`, or `hidden` (text-only, centred) |
| `youtubeUrl` | URL | — | When set, image column opens YouTube in lightbox |
| `videoPoster` | URL | — | Image in the side column |
| `backgroundImage` | URL | — | Full-width background behind both columns |
| `compact` | boolean | false | Shorter hero |
| `spacing`, `noTopSpacing`, `noBottomSpacing` | — | `comfortable` | Spacing controls |
| `hideOverlay`, `overlayColour`, `overlayOpacity` | — | — | Background overlay |
| `setHeroSeparators` + separator fields | — | — | Same pattern as **Hero Image** |
| `hideTitle`, `hideSubtitle`, `hideButton` | boolean | false | |

## Anti-patterns

- `imageColumnPosition: hidden` without strong title copy
- `youtubeUrl` without `videoPoster` (broken thumbnail)
- Very long description beside a small image column
- Multiple hero sections on one page

## Examples

```json
{
  "title": "Ship faster",
  "description": "Everything you need in one platform.",
  "buttonUrl": "/demo",
  "buttonLabel": "Book a demo",
  "config": {
    "imageColumnPosition": "right",
    "videoPoster": "/assets/img/product-shot.jpg",
    "backgroundImage": "/assets/img/hero-bg.jpg"
  }
}
```

With YouTube lightbox:

```json
{
  "config": {
    "youtubeUrl": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "videoPoster": "/assets/img/video-thumb.jpg"
  }
}
```
