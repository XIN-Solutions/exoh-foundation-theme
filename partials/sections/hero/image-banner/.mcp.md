# Image Banner

## Purpose

Centred hero with headline, subtitle, and CTA over a background image or video — simpler than **Hero Image** (no separators, no compact mode). Component name: **Image Banner** (`partials/sections/hero/image-banner/`).

## When to use

- Interior pages needing a shorter hero strip
- Campaign or category landing headers
- Background image or video with centred text
- When decorative separators are not needed

## When not to use

- Split text/image columns — use **Two Column Hero**
- Featured inline video player — use **Video Hero**
- Full homepage hero with shape separators — use **Hero Image**
- Body content with side image — use **Text & Image**

## Key fields and constraints

### Model fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string (HTML) | Recommended | Hidden when `config.hideTitle` |
| `titleId`, `titleClass` | string | Optional | |
| `description` | string (HTML) | Optional | Hidden when `config.hideSubtitle` |
| `descriptionId`, `descriptionClass` | string | Optional | |
| `buttonUrl` | URL | Optional | Pair with `buttonLabel` |
| `buttonLabel` | string (HTML) | Optional | Hidden when `config.hideButton` |
| `buttonId`, `buttonClasses`, `buttonTitle`, `buttonTarget` | string | Optional | |

### Config fields

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `spacing` | string | `comfortable` | Section spacing |
| `noTopSpacing`, `noBottomSpacing` | boolean | false | |
| `hideTitle`, `hideSubtitle`, `hideButton` | boolean | false | |
| `hideOverlay` | boolean | false | |
| `overlayColour` | string | `#000000` | |
| `overlayOpacity` | number | `0.7` | |
| `backgroundImage` | URL | — | Wide image (~1920px) |
| `backgroundVideo` | URL | — | Looped background; `backgroundImage` as poster |

## Anti-patterns

- Empty `buttonUrl` with visible CTA button
- Using as a second hero below **Hero Image** on the same page
- Portrait or low-resolution background images
- Hiding all text blocks with no background configured

## Examples

```json
{
  "title": "About us",
  "description": "Learn how we help customers succeed.",
  "buttonUrl": "/team",
  "buttonLabel": "Meet the team",
  "config": {
    "backgroundImage": "/assets/img/about-banner.jpg"
  }
}
```
